# 图片生成与编辑能力

服务来源中的协议预设只提供地址和接口说明。当前生成适配器支持 OpenAI Images 兼容协议与火山方舟的兼容生成端点；其他预设保存后不会自动接通图片生成。

OpenAI `gpt-image` 系列的参考图和蒙版编辑使用 `images/edits`，参考图和蒙版以 PNG 文件传输。普通未知模型默认只支持生成。自定义兼容服务需在“服务来源 → 图片编辑与蒙版能力”中，按供应商文档声明参考图支持、JSON/base64 或 PNG multipart、尺寸和画质。此配置声明兼容现有适配器，不会安装新的协议实现。

蒙版编辑还必须明确声明“透明区域可编辑”或“白色区域可编辑”。局部填充、空提示词移除、扩图均需要原图和蒙版；能力不足、缺图、缺蒙版和方向不一致时会阻止请求，不会改成整图生成。生成面板显示当前模型能力和声明的输出尺寸。

不支持的步数、引导强度、编辑强度和未声明的画质不会发送。声明了支持列表后，选中列表外的尺寸或画质会明确报错，尺寸中的空格与乘号会标准化。关闭“发送所选尺寸”后由供应商决定输出尺寸。

“单次多图”只请求一次。若转站只返回一张，其余槽位显示缺失；点击重试只请求缺失项。需要每张独立请求的服务请选择“分次生成”，并设置并发上限。未知结果不会自动重试，需先检查供应商调用记录。

目前验证使用固定 PNG、fetch 契约和本机原生请求构造测试，未进行付费服务调用，不代表已验证供应商权限、实际成图质量或费用。
