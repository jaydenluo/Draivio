# 选区生成填充与 AI 移除

在 AI 输入框选择“修改”。有选区时使用当前选区，未建立选区时作用于整个画布；提交前输入框显示范围。留空描述用于移除，填写描述用于替换。提交需要确认上传当前文档。

仅支持已声明蒙版语义的模型；内置识别 OpenAI `gpt-image*` 的透明区域编辑协议，其余模型需要来源配置明确声明 `imageCapabilities[model].maskedEdit.semantics`（`transparent-edit` 或 `white-edit`）。普通“支持编辑/参考图”不等于支持蒙版，未确认能力时禁用，不退回整图生成。浏览器和桌面端均向 `/images/edits` 提交 PNG 图像和 PNG 蒙版；服务实际权限及画面质量需要经授权的真实调用另行验证。

选区由画布物理像素生成，保留半透明与羽化；裁切包括边缘外的 32px 上下文。服务返回图片按裁切位置回贴，选区外像素不变。结果先进入“AI 结果”，不自动覆盖图层。可按局部编辑批次筛选、比较合成预览，在预览中展开完整服务原图、提交蒙版和生成前原图。

“新增图层”和“替换当前”均采用完整画布合成快照，确保透明返回和依赖背景的混合模式与预览完全一致。快照只改变选区内像素，完整保留生成时选区外的外观，原图层与参数不被破坏。“替换当前”绑定生成时目标，采用后选中新快照图层，来源目标保留在元数据中。

快照可独立隐藏、删除和撤销；隐藏或删除会恢复下方原始可编辑图层。快照可见时暂时抑制生成时捕获的源图层与背景，编辑这些原图层不会影响快照；先隐藏快照即可看到并继续编辑原始结构。采用后新建的其他图层照常显示，不会被快照抑制。文档在生成后发生改动时禁止采用过期快照，防止覆盖新内容。保存项目保留快照及全部原图层、源图、蒙版、原始返回和参数，重新打开无需重跑 API。

取消停止接收局部编辑结果及待提交请求；已提交请求仍可能计费。重试仍使用原始源图和蒙版，文档已变化时需要重新生成。
