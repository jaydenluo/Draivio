# AI 编辑记录与离线恢复

保存 `.draivio` 项目会保存已采用配方的版本、输入绑定、参数、实际执行步骤及其工具版本；一句话编辑记录保存目标、解析后的参数、实际变更与选择性逆操作，不保存规划提示词或服务认证配置。重新打开后，在一句话编辑的操作记录展开“步骤参数”查看执行内容；在“操作配方”选择已保存版本，再调参数、预览并采用。后续手动微调和新采用操作仍可撤销。

项目包含下载后的生成候选、原图、滤镜、蒙版及结构恢复所需图片。保存会把远端地址和临时 blob 转成项目内嵌资源，相同图片只存一份。资源下载失败时保存失败，当前作品保留；请在有网络时先完成保存。删除候选后再次保存，只保留仍被图层、其他候选或结构恢复记录引用的资源。

工作区会在编辑稳定约 900 毫秒后保存恢复副本。应用重开选择“恢复副本”，已下载候选可以无网查看、采用及编辑。恢复时不会自动重新请求供应商；如果上次快照记录了运行中的生成，在“AI 结果”会提示中断与远端结果未知。请检查供应商记录后自行决定是否新建请求，以免重复计费。尚未保存到恢复快照的瞬间状态无法恢复。

项目格式 3 兼容旧版 1、2；旧记录未写入参数/工具版本时仍显示现有执行结果，不编造缺失来源。未来格式、缺失资源或损坏恢复数据不会替换当前作品。恢复缓存沿用本地容量限制，超限或存储失败会提示保存项目文件。

认证头、API key、cookie、密码和访问令牌字段会在保存边界递归排除；疑似凭据文本或含认证查询参数的元数据 URL 会使保存失败，请移除后再保存。不要把密钥填写到作品文字或提示词中。
