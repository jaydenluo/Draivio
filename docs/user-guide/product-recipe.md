# 产品抠图、背景与接触投影

在紧凑 AI Composer 点“产品抠图与投影”。先选顶层普通商品图片，使用“分析商品主体蒙版”在现有分割工具里接受主体蒙版，或手工创建/精修启用的图层蒙版。配方不会猜测主体，也不会把整张图片作为假抠图结果。嵌套组、智能对象、含独立文字/绘制对象和特殊图层需先创建普通图像副本，原稿保留。

选择纯色背景，或选择另一顶层普通图片作为背景。生成背景需明确点“转到背景生成入口”，在现有入口填写背景描述、确认请求，再将已生成结果采用为图层，回到产品配方选择它。切换入口本身不发请求、不会上传或重绘商品。

默认商品位移为零，保持原商品资源和变换。预览中的瓶身文字/几何只通过原蒙版显示，不经过生成模型。可调整商品位置、投影接触水平/垂直位置、宽度、压扁比例、模糊与透明度。接触投影是可调椭圆近似，不是光照物理推理；请检查脚底/底座并调整接触位置。

点击“采用产品配方”会新建商品保护层、独立接触投影和背景，隐藏原商品层，原图和原蒙版继续保留。商品蒙版原样复制，玻璃、反光和镂空不佳时，选商品保护层点“手工精修商品蒙版”，用现有蒙版画笔和边缘细化修正；不会静默重绘。投影层可以单独移动、隐藏或调整透明度。选择商品保护层重新打开配方，可读取已保存参数并创建新版本。

预览和取消不写作品；切换文档或内容已更改会使旧预览失效。采用是一个整体撤销操作。项目保存包含商品源图、蒙版、独立投影与背景、参数来源，可无网重开继续编辑。文档空间阴影/背景和商品渲染使用同一画布与导出链路。

固定测试样例的前后图与导出图在 docs/implementation/product-recipe；它们验证瓶身笔画像素、镂空、半透明 alpha、阴影及持久化，不代表分割模型的识别准确率。
