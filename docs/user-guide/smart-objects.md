# 智能对象

在图层面板选择普通图片、文字或形状图层，点击“转换为智能对象”。图层的原始内容被嵌入为独立源，位置、变换、蒙版和效果仍保存在实例上。缩小后再放大时继续从源内容采样。

普通“复制”共享同一源；“建立独立副本”复制一份源，之后可单独编辑。替换内容和保存内部编辑会更新共享实例，但保留各实例自己的位置、蒙版、透明度与效果。共享实例中存在锁定层时，源编辑被阻止，先解锁后再修改。

双击智能对象缩略图或点击“打开内部文档”打开独立草稿。可以编辑内部文字和形状颜色，并预览结果。“保存并回写”将草稿作为一次父文档撤销操作提交；取消关闭会询问是否放弃草稿，父文档不变。当前内部编辑器只提供文字内容和形状填色；其他图形结构仍保留在源中。

“替换内容”接受本地 PNG、JPEG、WebP、GIF 图片（最大 32MB），读取和解码成功后才修改源。异步期间切换文档或修改源，旧结果会被丢弃。内部文档和源资源跟随父项目保存，不单独写入外部链接文件；离线重开项目可恢复源内容及实例关系。未回写草稿不属于父项目保存内容。

“栅格化智能对象”将源内容按原始尺寸输出为 PNG，并保留实例变换、蒙版和效果；撤销可恢复智能对象与源引用。循环引用、缺失源和超过 8 层的嵌套会被拒绝。首版不支持分组/调整图层直接转换、外部链接文件监听或 PSD 智能对象兼容。
