# 剪贴蒙版与混合模式

在图层面板选中上方图层，点击「创建剪贴蒙版」。它只显示在同组内紧邻下方基底的不透明区域；下方若已经剪贴到另一个基底，则加入同一剪贴链。列表显示「剪贴至 基底名称」，再次点击「释放剪贴蒙版」恢复完整内容。

半透明文字、形状、图片、蒙版与调整都参与基底 alpha。整条剪贴链只使用一次基底 alpha，不会因叠加更多剪贴层而增加边缘透明度。基底与剪贴内容分别移动：基底移动会改变可见范围，剪贴层移动会改变范围内部的内容。

基底被删除、跨组移动或链被重新排序/释放而中断时，失效链明确释放，不自动猜测新基底；撤销可完整恢复。锁定图层不能创建或释放剪贴关系，若结构修改会间接释放锁定层，操作会拒绝。删除、分组等原有操作的锁定规则继续生效。

混合模式下拉按正常、变暗、变亮、对比、比较和颜色分类，支持正常、变暗、正片叠底、颜色加深、变亮、滤色、颜色减淡、叠加、柔光、强光、差值、排除、色相、饱和度、颜色及明度。混合在 sRGB 中执行，透明像素使用预乘 alpha 合成；预览与 PNG/JPEG/WebP 导出共用同一个 SVG 场景。项目导入遇到不支持的模式或无效剪贴关系会提示错误，不会静默改成正常。

合并时请同时选择可见基底和完整剪贴链。只选择链的一部分或包含隐藏链成员时，合并会拒绝并保留作品；可以先释放剪贴后再单独栅格化，或选中完整可见链合并。参与外部剪贴链的图层组也不能直接解组，需要先合并完整剪贴链或释放关系。
