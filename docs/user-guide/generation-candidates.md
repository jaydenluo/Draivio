# 生成候选与采用

第三方图片服务的生成结果先保存在「AI 结果」。收到候选不会新增正式图层、切换当前图层或写入画布内容撤销历史。可先预览、比较和保留多张候选，再点「新增图层」采用；采用是一个可撤销步骤，撤销会恢复未采用的候选。纯生成候选同一张只采用一次，避免意外双击产生重复层。

同批次成功候选可逐张采用；已经采用的图层保持原样时不会让同批其余候选失效。修改原文档内容或已采用结果的混合、调整、变换等内容后，旧候选的采用会被拒绝，需要重新生成。仅切换视图或选择不使候选失效。替换现有图层同样检查原上下文和图层/祖先锁定。

部分请求失败时保留已收到的候选，并只重试失败/缺少的项。取消停止后续请求并丢弃迟到结果，已有成功候选继续保留为未采用结果。网络结果未知时会明确提示可能重复计费，不自动重新请求。凭据不写入候选或文档。

局部蒙版合成采用后，请先撤销本次采用再切换或重复采用候选；这样不会用旧快照遮住之后的编辑或锁定图层。收到局部编辑、扩图和超分候选同样保留原来的撤销及重做记录。

项目保存包含候选图像和来源信息，离线重开后仍可预览和采用。局部编辑、移除和扩图继续使用各自的合成/蒙版/画布保护规则；正式图层都在明确采用后产生。

Draivio 官方云端尚未配置真实生图服务，入口明确提示不可用；不产生模拟结果或扣款。第三方HTTP契约测试不代表进行过真实付费模型调用。
