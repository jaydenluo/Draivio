# 移除画笔与内容识别填充

选择普通图层，先框选要移除的区域，在选区工具参数栏或画布右键菜单点击“内容识别填充”。也可在橡皮擦/修复工具组选择“移除画笔”，在画布拖动后进入同一工作区。

工作区不会直接修改原图。红色为待填区域，绿色为可采样区域，蓝色为保护区域；可通过画笔或百分比矩形添加覆盖。手动采样只允许绿色区域作为原始供体；保护区域既不被写入，也不参与上下文与供体匹配。切换绘制区域后，“清空当前覆盖”只清除该区域；“自动采样”恢复使用待填和保护区域以外的原始像素。

点击“预览补洞”后可“比较原图”。确认输出一张仅含实际变化像素的新图层；隐藏该图层或撤销可恢复原图。预览、取消、停止计算、失败不增加历史记录。修改文档、切换图层或选区会使旧结果失效，防止跨文档写入。保存项目后重开直接使用已保存的 PNG 和方法参数，SVG 导出同时保留资源和方法元数据。

当前提供明确标注的本地邻域纹理算法 `local-context-patch-v1`，不调用云服务，不产生计费。它使用已知 5×5 邻域匹配不可变原始供体，适合小面积重复纹理、平滑天空与简单边缘；复杂物体和语义内容不保证自然恢复。固定测试分别使用 16×12 棋盘纹理、纵向天空渐变与水平跨边缘，中心 2×4 污染区补洞后平均单通道误差必须小于 40/255，区外像素精确不变。保护供体“毒色”与保护区重叠目标另有精确测试。

本地处理限制：图像最多 4,194,304 像素，目标最多 16,384 像素且不超过图像 75%；候选供体最多 768 个，计算预算 40,000,000 次邻域操作，默认 10 秒。达到任一预算、没有有效供体、保护区隔断已知边界、未产生变化都会明确失败，请缩小区域或调整采样后重试。取消支持初始扫描和填充阶段；最大目标取消测试要求 1 秒内响应，不写入部分结果。
