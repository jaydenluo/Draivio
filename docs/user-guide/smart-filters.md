# 智能滤镜

在“图层”列表中展开目标图层下的“智能滤镜”，或在“属性”中打开同名区域。当前提供高斯模糊、锐化和高反差保留。点击添加后可查看临时预览；默认半径及强度为零，保持原图。确认后才写入历史，取消或按 Escape 关闭预览不会更改作品。

点击或双击已有滤镜可重新编辑参数。复选框启停单个步骤，拖动步骤或用上下箭头调整执行顺序。滤镜按照列表从上到下计算；锐化和模糊在不同顺序下可能输出不同结果。每一步都从完整源内容重新计算，反复编辑不会损伤原始图片。最多保留16个步骤。

半径以**图层本地像素**为单位，上限64像素，用于限制计算与内存成本；超出上限会提示原因并禁用确认。锐化/反差保留强度为0–5。高反差保留输出以中灰为中心的细节，可配合图层混合模式使用。默认参数及停用全部步骤都精确恢复原图。

在参数窗口中可启用独立滤镜矩形蒙版。X/Y/宽/高使用图层本地0–100%坐标；蒙版只限制滤镜的作用范围，范围外保留源像素，不裁去图层，也不改变已有图层蒙版。可以反向处理矩形外区域。首版不提供独立滤镜笔刷蒙版。

智能对象的内部内容或共享源更新后，滤镜立即对新内容重算，实例尺寸和变换保持不变。文档或源内容在参数窗口打开期间发生改变时，确认被禁用；取消后重新打开即可基于新版本预览。锁定图层及继承锁定的图层禁止修改滤镜。

撤销/重做和项目保存重开保留参数、开关、顺序和独立蒙版。临时预览图不会写入源图。画布、缩略图和最终SVG/PNG导出共用同一SVG处理图。底层CPU离屏参考接口支持取消和最新任务优先；编辑器原生SVG渲染由浏览器执行，关闭预览会卸载处理图并立即返回作品视图，浏览器内部正在计算的单次SVG操作无法逐行中断。CPU参考离屏接口为最多1600万像素，SVG编辑器仍沿用文档自身尺寸上限。

CPU参考使用截断到3σ的精确离散高斯核；浏览器/原生SVG后端可使用近似高斯。固定单像素脉冲样例中，Resvg中心值63、CPU中心值41，8位通道最大差异不超过24；两者不宣称逐像素相同。实际编辑和最终导出都使用同一SVG后端，项目往返与撤销重做的像素严格一致。

## 常用模糊与风格滤镜

添加“方向运动模糊”可设置半径和方向角；“径向模糊”以图层中心为中心执行多样本缩放模糊，半径决定采样的缩放跨度。半径0不改变图像。“像素化”用1–64像素方块平均，尺寸1保持原图。颗粒和晕影强度0–1，默认0保持原图。颗粒种子为0–2147483647整数，同一源、参数和种子得到同一结果；不改变透明度。

这些滤镜只支持8位RGBA处理；高精度文档/源会禁用添加，不会在后台悄悄降精度。每层离屏处理上限1600万像素。大图超过限制时显示错误并保留源图。可先明确转换为8位、缩小图层，再使用。

运动、径向和高斯采用透明边界、预乘alpha采样；像素化对RGB按alpha加权，避免透明黑色污染边缘。模糊可以扩散透明度，颗粒与晕影保留alpha。高级链通过CPU统一渲染，画布临时预览和导出使用同一个处理函数及参数；导出等待计算完成。CPU结果是临时派生显示图，不写入原始source，项目保存的仍是源图与可编辑参数。原有只含F18基础滤镜的链继续使用SVG；混合链有高级滤镜时整条链转CPU，以保证次序一致。

参数窗口可点击“使用当前选区限制滤镜”，将选区快照转换到图层本地空间；羽化和复杂选区保留，选区外原像素不变。此快照随项目保存，之后更改画布选区不会改变已确认的滤镜。可以清除选区，或与独立矩形滤镜蒙版叠加。取消窗口立即卸载草稿并取消CPU工作，文档和历史不变。计算期间显示源图，完成后更新预览；失败显示原因并保留源图。

一句话编辑也可规划这些滤镜，例如“运动模糊 半径3 方向90”“颗粒 强度0.2 种子42”“像素化 尺寸4”。仍需先确认计划、查看临时效果并采用，写入后可一次撤销。未给参数默认中性；不会自行猜测强度。
