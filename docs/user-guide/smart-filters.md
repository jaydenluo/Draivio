# 智能滤镜

选中目标图层后，点击图层行右侧的滤镜图标，或右键选择「添加智能滤镜」。添加后，点击同一个图标展开或收起滤镜列表。列表右侧的「＋」用于添加更多滤镜，属性面板的滤镜数量可定位到这组滤镜。

添加滤镜时会带入可预览的起始参数。单击滤镜名称打开可拖动的参数窗口，可以确认目标图层和作用范围，用滑杆或数字输入调整。在当前图层添加首个滤镜时，如果画布已有选区，会默认使用该选区。可以取消勾选「仅处理当前选区」以处理整层。形状与图片同在一个图层时，整层范围会一起处理该层内容。

计算时画布顶部显示「滤镜预览计算中…」，结果可以显示后才替换当前画面。读取或渲染失败会显示原因。按住「按住对比」可以暂时关闭正在调整的滤镜。点击「应用」记入一次撤销，点击「取消」、右上角关闭或在窗口内按 Escape 即可恢复已应用的效果。

点击眼睛启停单个滤镜。拖动可调整顺序，也可以从「⋯」菜单选择上移、下移或删除。滤镜按列表从上到下处理，每次从源内容重新计算。最多保留 16 条。

半径以**图层本地像素**为单位，上限 64 像素。锐化和高反差保留的强度为 0–5。高反差保留输出以中灰为中心的细节，可配合图层混合模式使用。停用全部步骤会恢复原图。降噪阈值为 0 时保留原像素，参数窗口会显示提示。

滤镜标题行的「＋」左侧显示当前作用范围。点击文字可选择「全图层」或「设置局部范围…」。切回全图层时会清除选区快照、停用矩形蒙版并保留矩形参数，此操作可以撤销。局部范围窗口可为整组滤镜启用矩形蒙版。位置和大小使用图层本地 0–100% 坐标，也可切换为仅处理矩形外侧。范围外保留源像素，图层蒙版继续独立生效。

智能对象的内部内容或共享源更新后，滤镜立即对新内容重算，实例尺寸和变换保持不变。文档或源内容在参数窗口打开期间发生改变时，确认被禁用；取消后重新打开即可基于新版本预览。锁定图层及继承锁定的图层禁止修改滤镜。

撤销/重做和项目保存重开保留参数、开关、顺序和独立蒙版。临时预览图不会写入源图。画布、缩略图和最终SVG/PNG导出共用同一SVG处理图。底层CPU离屏参考接口支持取消和最新任务优先；编辑器原生SVG渲染由浏览器执行，关闭预览会卸载处理图并立即返回作品视图，浏览器内部正在计算的单次SVG操作无法逐行中断。CPU参考离屏接口为最多1600万像素，SVG编辑器仍沿用文档自身尺寸上限。

CPU参考使用截断到3σ的精确离散高斯核；浏览器/原生SVG后端可使用近似高斯。固定单像素脉冲样例中，Resvg中心值63、CPU中心值41，8位通道最大差异不超过24；两者不宣称逐像素相同。实际编辑和最终导出都使用同一SVG后端，项目往返与撤销重做的像素严格一致。

## 常用模糊与风格滤镜

添加「方向运动模糊」可设置半径和方向角。「径向模糊」沿图层中心采样，半径决定缩放跨度。半径为 0 时保留原图。「像素化」用 1–64 像素方块平均，尺寸为 1 时保留原图。颗粒和晕影强度为 0–1，强度为 0 时保留原图。颗粒种子为 0–2147483647 的整数，同一源、参数和种子得到同一结果并保留透明度。

这些滤镜只支持8位RGBA处理；高精度文档/源会禁用添加，不会在后台悄悄降精度。每层离屏处理上限1600万像素。大图超过限制时显示错误并保留源图。可先明确转换为8位、缩小图层，再使用。

运动、径向和高斯采用透明边界、预乘alpha采样；像素化对RGB按alpha加权，避免透明黑色污染边缘。模糊可以扩散透明度，颗粒与晕影保留alpha。高级链通过CPU统一渲染，画布临时预览和导出使用同一个处理函数及参数；导出等待计算完成。CPU结果是临时派生显示图，不写入原始source，项目保存的仍是源图与可编辑参数。原有只含F18基础滤镜的链继续使用SVG；混合链有高级滤镜时整条链转CPU，以保证次序一致。

选择「设置局部范围…」后点击「使用当前选区」，可将选区快照转换到图层本地空间。羽化和复杂选区随项目保存，后续修改画布选区时仍使用已保存的快照。选区可以清除，也可以与矩形叠加。关闭窗口会取消草稿及其 CPU 计算。处理期间画布显示源内容，完成后更新效果。

一句话编辑也可规划这些滤镜，例如“运动模糊 半径3 方向90”“颗粒 强度0.2 种子42”“像素化 尺寸4”。仍需先确认计划、查看临时效果并采用，写入后可一次撤销。未给参数默认中性；不会自行猜测强度。

滤镜菜单按模糊、细节、色彩和风格分组。黑白、复古棕色、反相、色调分离、二值化和浮雕支持调节强度。色调分离可选色阶数，二值化可调明暗分界阈值。这六种效果保留图层透明度。

- **方框模糊**对邻域均匀取平均，适合快速柔化。半径以像素计，模糊会扩散到透明边缘。
- **中间值**用邻域中间值减少孤立杂点。半径可设为 1–4 像素，保留原透明度。
- **查找边缘**根据明暗梯度提取轮廓。强度越高，轮廓越明显。
- **柔光发光**将超过阈值的亮部扩散到附近，适合灯光和高光。可调整强度、半径和高光阈值。
- **双色调**将原图的明暗映射为阴影色和高光色，可分别选色，并用强度控制与原图混合的程度。
