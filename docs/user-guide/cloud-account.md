# 云服务与账户

默认连接 `https://www.moviviz.com`，与幕影使用同一套账号和积分。

## 使用入口

1. 顶部“账户与设置” → “登录 / 注册”。支持密码登录、验证码登录、注册和找回密码。
2. 如需使用另一部署，展开“云服务地址”，填写并保存服务域名（例如 `https://www.moviviz.com`）。不要附加 `/api` 或 `/v1`。支持 HTTPS，以及本地开发用的 loopback HTTP。
3. 登录后，模型选择器显示云端返回且声明可用的模型；自定义供应商仍使用各自的密钥与额度。
4. 云端生图会先查询报价，再确认提交。多张图片采用单张拆分请求，报价按请求数量累计。手动补齐也会重新报价。
5. 账户菜单显示实际积分，可打开充值窗口读取云端套餐和支付渠道。选择套餐后创建云端充值单，二维码支持微信/支付宝，窗口会轮询订单状态，支付成功后刷新积分。

## 配置与会话

- 构建默认域名可通过 `VITE_CLOUD_API_ORIGIN=https://www.moviviz.com` 设置；登录窗口保存的地址优先，保存键为 `draivio-cloud-origin`。
- 更换服务地址会清除当前会话；旧登录和排队生成不能继续使用原凭证。配置地址与设备 ID 可保存在本地，密码与 access/refresh token 只保存在内存，不写入作品或 localStorage。
- 关闭应用或刷新页面后需要重新登录。当前会话的令牌过期由单次合并刷新处理。
- 浏览器预览使用统一 HTTP 封装，需要服务允许跨域；桌面使用 Tauri 原生桥，限定请求路径和方法，不跟随重定向。

## 计费与能力边界

- 积分冻结、扣费、结算和失败退款由云服务处理；客户端不自行扣减余额。
- 生图请求携带幂等键，401 刷新后复用相同键；网络中断或未知结果不会自动重新付费提交。手动重试可能另行计费，需先检查服务方使用记录。
- 只有目录明确可用且声明图片/文本能力的模型才进入对应选择器。当前官方目录缺少可验证的蒙版契约，暂不开启云端蒙版编辑。
- 此接入使用登录会话。文档注明尚未上线的 API Key 管理接口未接入。
