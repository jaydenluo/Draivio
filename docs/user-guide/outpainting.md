# 生成扩展

选择裁剪工具，在工具选项点击“生成扩展”。可拖动四边或右下角、输入最终像素尺寸与边距、选择常用比例和九宫格原图锚点。原图不拉伸，原图矩形内包括透明像素的四个通道保持不变。

窗口实时显示最终尺寸、原图偏移、端点输入上限、分块重叠和准确请求次数。默认保守上限为 1024px；有明确模型限制时使用来源配置 `imageCapabilities[model].maskedEdit.maxDimension`（64–2048）。输入过大时会规划有重叠的分块，最多 64 次、1600 万像素，超出即禁用。每块是带参考 PNG 和蒙版 PNG 的真实 `/images/edits` 编辑请求；原图区域永远不进入可编辑蒙版。

勾选“确认上传原图，并提交上述…次可能计费的编辑请求”后才能开始。调整范围会清除此确认。不会自动重试失败或追加未列出的请求。按靠近原图顺序生成分块，在外部重叠区域羽化混合；不会羽化或改写原图。若服务返回留下透明洞，整个候选拒绝采用，原画布不变。模型真实扩图视觉质量需要授权服务调用另行验证。

生成结果先进入 AI 结果，可预览和展开每块的蒙版、原始返回及原图。“采用扩图”一次性改变画布尺寸并加入完整画布快照，原图层保留；撤销同时恢复原尺寸与内容。快照可见时显示冻结的合成外观，隐藏或删除快照恢复原可编辑图层。保存项目会保留源图、分块蒙版、服务原始返回、坐标、限制、偏移和参数，重新打开无需请求模型。

取消或失败不改变文档；锁定目标不能执行。生成期间改变文档内容会丢弃过期结果，采用前改变画布也会拒绝过期候选。接口不支持明确蒙版语义时禁用，不退回文生图。
