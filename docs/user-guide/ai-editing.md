# AI 编辑：五条实际工作流

本文对应当前本地候选版本，尚非跨平台完整发布验收。作品编辑在本机进行；只有明确选择供应商模型并确认请求时才发送对应上下文或图片。官方 Draivio 云端未接入生成、余额与支付服务，不能以默认模型名称判断已经可用。

## 开始前

从账户菜单打开「服务来源」，填写 HTTP(S) 地址、协议、模型 ID 与本次会话的密钥。当前图片生成与模型规划接入 OpenAI 兼容和火山兼容接口；其他协议出现在配置中不等于已有执行器。推理模型需声明文本能力；参考图还需视觉能力。图片编辑需明确声明蒙版编辑能力，未支持时不能自动改用整图生成。

浏览器仅持久化服务元数据，密钥留在当前进程内存，刷新后需重新输入。桌面端服务来源与密钥目前仅在进程会话保留，重启后重新配置；不提供系统凭据库持久化承诺。旧明文存储会被清理，不能依赖旧数据库自动恢复密钥。不要把密钥放入作品文字、提示词或项目文件。

文件的新建、打开、保存与另存为位于顶栏；RAW、普通批量、画板管理、文档尺寸与 CMYK 位于「更多工具」。

## 1. 基础：移动图层并保留撤销

1. 打开图片，选择要编辑的图层，在 Composer 进入「一句话编辑」。
2. 选择「离线规则（不调用模型）」，输入「向右移动10像素，然后旋转15度」。核对「编辑范围」是选中图层还是整个文档。
3. 执行只生成计划；检查目标与参数，再「确认执行计划」。查看实际前后预览，必要时调整数值。
4. 「采用预览」才写入作品。撤销恢复采用前的状态；放弃预览不改作品。

局部像素选区不会限制图层移动、旋转等整体变换。锁定图层或锁定祖先不能被模型绕过。目标含糊时需要重新明确，不能把名称猜测当授权。

选择「模型推理」会调用配置的推理模型，确认框说明发送图层上下文与可能计费。通过「添加参考图」显式选择本地 PNG/JPEG/WebP，只有视觉模型可接收，确认后随请求发送；离线规则不使用参考图。不支持工具、无效 JSON、越界目标、文档已改动或取消后的响应不会写入作品。

## 2. 局部：选区内替换或移除

1. 选择普通图片图层，使用选区工具圈定区域；检查选区边缘、孔洞与羽化。
2. 在「修改当前图」选择已声明蒙版编辑能力的自定义模型。输入替换内容；空提示词表示移除。
3. 阅读上传确认，随后核对请求次数、供应商、费用估算或「费用未知」提示。任一确认取消都不发送该次生成请求。
4. 等待结果，在「AI 结果」检查候选后采用。选区外像素按原图保护，原图保留；选择错误应重新圈定后请求。

图片内容会上传到所选供应商。计费以供应商为准，未知单价不能显示成免费。取消只停止本地等待及可取消请求，不能保证远端停止或退款。网络失败、结果未知时先查供应商请求记录，再决定重试；重试再次确认费用，成功的结果不需要重复生成。

## 3. 配方：电影色调并继续微调

1. 选择目标图片，在 Composer 打开「操作配方」，选择「暖色电影」「冷色电影」「黑白电影」或「复古电影」。
2. 检查输入图层与参数，点击「预览配方」，切换前后查看实际画布。
3. 「采用配方」一次写入，可整套撤销。已保存版本可在「重新编辑已保存配方」重新绑定、调参、预览。

当前通用配方只运行本地已注册工具，不自动调用收费模型。双重曝光需要显式第二图，可选择图层、本地导入或已经下载的结果；不提供第二图会阻止预览。它不自动识别主体，不透明主体需先建立轮廓选区或蒙版。不同配方有各自输入与精度限制；不支持的层类型和锁定目标会明确拒绝。

## 4. 批量：先试跑，再处理剩余文件

1. 打开 Composer 中的「配方批处理」，保留默认透明度配方，或复制已保存的本地配方。
2. 选择图片文件与输出目录，检查输入槽、参数、前缀及并发（1 或 2）。
3. 「试跑第一张」，打开下载/输出结果核对，再开始剩余批量。
4. 查看逐项状态；只重试失败项。写出结果未知时先核对目标目录，不能盲目重写。

每张图片使用独立文档事务，不修改当前作品。当前配方批处理不执行模型调用：模型请求和费用为 0；预算上限是保守预留，不代表已经支持远程收费批处理。取消不会删除已经输出的文件。浏览器目录访问取决于浏览器文件权限，未支持的目录 API 不承诺与桌面一致；历史结果受本地容量与权限限制。

## 5. 保存、离线恢复与失败后继续

1. 完成编辑后保存 `.draivio`，等待资源嵌入完成；远端资源尚未下载或获取失败时保存会报错，先联网下载后再保存。
2. 关闭并重开项目，可离线查看已嵌入图层、已下载候选、蒙版、已采用配方与参数。打开项目不自动重新调用供应商。
3. 意外退出后选择「恢复副本」。工作区稳定约 900 毫秒后写入恢复缓存，刚发生而未进入快照的状态可能丢失；缓存超限时主动保存文件。
4. 上次请求仍显示中断/结果未知时先查供应商记录。离线无法新发模型请求；需要继续请求时重新输入会话密钥。

项目支持旧格式 1、2 迁移到格式 3；损坏或未来版本不会替换当前作品。撤销历史不承诺跨应用重启完整保留。更多边界见 [离线恢复说明](ai-editing-recovery.md)。

## RAW 与能力边界

顶部「更多工具 → RAW 显影」需要桌面本地 Python 3.11+、rawpy 0.28 和 Pillow，缺依赖明确失败，不会把内嵌 JPEG 当 RAW 成功。实测 Canon EOS40D CR2、Nikon D2H NEF、Sony ILCE-7S ARW；不保证所有相机。当前半尺寸 16 位 sRGB 输出，原始文件上限16MiB、传感器6000万像素、输出资源32MiB。曝光、白平衡和高光重建先预览后确认，保留 RAW 字节和参数，可离线恢复并重开；导出走 ICC 管线。安装、许可、实际矩阵见 [RAW 说明](../raw/README.md)。浏览器没有原生 RAW 后端。

放大、修复、生成和保边降噪不能保证恢复原照片中不存在的真实细节；不要将模型补画当原始事实。当前不声明完整 Photoshop 文件/滤镜/插件兼容，也不保证浏览器、macOS、Windows在文件访问、字体、原生编解码方面完全等价。

## 分阶段验收

本地候选阶段的五条流程有组件、像素、导出与恢复自动化证据，仍需独立审核；自动测试不代表实际用户已经完成五条任务。完整目标还需要真实供应商质量、用户流程和目标平台验收，单独保留在任务 `6bab7ff2-efdb-4bea-92c4-4736f6cc4f83`。语义目标定位、分割与蒙版工具，以及 AI 生成编辑与工作流任务已通过各自当前周期验收；这不等于所有真实供应商、人物和平台上的质量保证。云余额支付和未验证平台能力仍不能标为完成。实际用户五流程记录见 [用户验收包](../release/user-five-flow-validation.md)，当前尚未执行；本文不构成发布或部署。
