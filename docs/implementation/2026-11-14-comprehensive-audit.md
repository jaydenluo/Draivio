## 部分完成或有边界

- 真实 API 生图只允许 `openai_compatible` 与 `volcengine`；其他协议明确拒绝。浏览器端仍受 CORS 约束，桌面端走 Tauri command。
- OpenAI 兼容参数支持 `n/size/quality` 的能力开关；中转站不支持多图时，通过模拟/批量请求路径逐张生成，但真实供应商端到端仍没有付费 API 证据。
- 账户下拉菜单已扩展图标、说明和“退出登录”项，但退出登录仍 disabled，因为当前没有登录会话实现。
- 服务密钥存于本机 SQLite 或浏览器 localStorage 明文，项目文件不会导出密钥；这是当前产品边界，不是安全存储完成。
- 画笔、橡皮、填充、仿制、涂抹、背景橡皮等路径有 reducer/组件和异步过期测试；真实浏览器尚未逐项完成 39 个工具的完整像素、历史、保存、导出审计。
- 大图 WebKit/Tauri 性能、复杂变换下的透明边缘卷积、真实桌面文件选择器和关闭拦截仍缺证据。
