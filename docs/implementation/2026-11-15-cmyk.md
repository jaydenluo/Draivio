# CMYK 文档与 TIFF

顶部「文档模式 / CMYK」提供当前画板的 RGB→CMYK 转换。转换会合并为 8 位四通道像素，透明区域铺白；原 RGB 图层保存为项目源，转换可以一次撤销，也可恢复原图层。支持直接输入指定像素的 C/M/Y/K 百分比，先预览后采用。

桌面后端调用本机 Python 3 + Pillow（LittleCMS2、libtiff），不执行用户脚本。未安装依赖会明确报告不可用。macOS 可使用本机 Generic CMYK profile；它不随仓库或应用分发。其他平台或实际印刷请上传印刷商提供的 CMYK ICC，最大 4 MiB。最多处理 400 万像素。

设备 CMYK 通道和 ICC 保存在项目中，RGB 图像仅是经 ICC 生成的显示缓存。CMYK TIFF 导出直接写这些通道，嵌入同一 ICC，并重新打开文件校验四通道、样本和 ICC。普通「导出」在 CMYK 模式进入同一对话框，不会误标 RGB PNG 为 CMYK。

总墨量警戒线可按印刷要求填写，超出时显示警告，不擅自缩放四通道破坏 profile 的黑版生成。转换可能压缩超色域颜色并损失精度；屏幕不能保证任意设备的实物颜色。本项不提供 PDF/X、专色或多通道。

RGB 滤镜、图层修改和 AI 文档写入在 CMYK 模式明确阻止。选择「显式创建 RGB 工作副本」后，使用 ICC 生成的 RGB 预览作为工作副本，同时保留 CMYK 原通道和撤销路径。

本机验证产物保存在 `/tmp/cmyk-verification/`，不将系统 profile 拷入仓库。四通道 TIFF 独立读取为 CMYK、8/8/8/8 bit、Photometric=5、ICC 55280 bytes；固定色条最大总墨量约 294.1%，通道逐字节保持。完整证据以执行报告为准。
