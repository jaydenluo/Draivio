# 选择并遮住

## 已实现

- 从“选区”工具选项打开临时的「选择并遮住」工作区。
- 画布保持可见，右侧浮出轻量精修面板；关闭或取消不会污染原选区。
- 预览模式：叠加、黑底、白底、透明背景。
- 边缘精修：增加选区、减去选区、画笔大小，以及按住 Shift 临时反向。
- 边缘属性：羽化、单步收缩、扩展。
- 输出方式：更新选区，或将当前精修结果输出为图层蒙版。
- Escape、关闭按钮、取消按钮都可退出精修工作区。

## 当前边界

当前版本使用现有选区几何与 SVG 蒙版完成基础精修，适合矩形、椭圆、路径和布尔选区。Photoshop 中更高级的“边缘检测、发丝细节、颜色净化、AI 边缘优化”仍属于后续能力，暂时没有在界面上伪装成已支持的算法。

## 关键实现

- `src/components/SelectionRefinePanel.tsx`：精修面板与输出设置。
- `src/app/AppShell.tsx`：临时草稿状态、取消恢复和最终提交。
- `src/canvas/CanvasViewport.tsx`：画布加选/减选笔刷与选区外预览。
- `src/styles/theme.css`：右侧浮动面板和预览样式。
