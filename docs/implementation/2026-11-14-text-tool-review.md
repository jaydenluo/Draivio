# 文字工具现状检查与 Photoshop 式交互建议

日期：2026-11-14。性质：代码审查和待确认的产品方案，本轮未修改文字功能代码。

关联任务：F14「文本框、段落排版与局部文字样式」，79956f5e-d48e-4ef3-90d9-575117f1a6d5；当前 backlog、版本 3。延续画布优先、Tauri、中文和用户系统字体的要求。

## 结论

当前文字功能具备基础字符串输入与 SVG 显示，但尚不构成可用于海报排版的文字工具。建议沿用 Photoshop 的点文字、段落文字、独立文字图层和上下文属性习惯，保留 Draivio 紧凑的界面。

本报告依据当前代码，不宣称已在 Photoshop 或 Windows/macOS 原生环境完成实测。尝试读取 Adobe 官方 add-edit-text 文档时得到 HTTP 403，故不将其列为本次已经核验的在线资料。下列交互是拟采用的产品规则，不代表 Photoshop 每个版本都完全相同。

## 已确认的代码问题

| 问题 | 代码依据 | 对用户的影响 |
| --- | --- | --- |
| 参数只修改新建默认值 | ToolOptionsBar 的 setOption 仅派发 set-tool-options；reducer 不更新 canvasTexts | 改字号、字体、颜色后，已存在文字不变 |
| 点击创建占位文字，未立即输入 | CanvasViewport.down 写入「双击编辑文字」后返回 | 添加文字需要再次双击，没有即时光标 |
| 文字没有独立图层 | 新对象复用 selectedLayerId，未创建 text layer | 移动、复制、删除和变换的目标是整层，容易牵连图片或其他文字 |
| 缺少文字对象选择 | selected 仅判断 layerId，点击文字也仅 select-layer | 同一层的多段文字会一起显示选中，无法准确绑定参数 |
| 无点文字/段落文字数据 | CanvasTextObject 无模式、宽高、段落或样式区间 | 无法拖出固定宽度文字框、自动换行、调整行距字距和局部颜色 |
| Enter 提交而非换行 | TextObject.onKeyDown 拦截普通 Enter | 与长段文字输入习惯不一致，换行需要额外修饰键 |
| 失焦即提交 | textarea.onBlur 调用 finish(true) | 点击字体、颜色或其他参数时，编辑会先结束，无法保持文字范围 |
| 编辑框缩放不持久 | CSS textarea resize:both，但无尺寸事件或宽高字段 | 拖动输入框大小仅改变临时 DOM，退出后不保留 |
| 两套排版不一致 | SVG textAnchor 按锚点对齐、行距 1.4；HTML 编辑框从 left/top 定位、行距 1.2 | 中/右对齐及多行文本存在编辑命中框、光标和显示位置不一致的风险 |
| 字体检测不足 | document.fonts.check 被当作系统字体安装证明 | 可能使用回退字体却显示为可用，也未枚举本机字体和实际字重 |
| 属性面板未适配文字 | PropertiesPanel 显示整层尺寸和图像调整 | 缺少字符/段落排版控制；图层框尺寸容易误当成文字框尺寸 |

目前测试主要证明双击、失焦提交、Esc 取消及画布尺寸变化后仍可进入输入框。它们不证明字体参数联动、文字边界、富文本、段落换行或最终导出的排版一致性。

## 路线比较

1. 继续修补 textarea：适合临时标注；投入较小，但无法满足局部样式和成熟段落编辑，不推荐作为目标方案。
2. 独立文字图层 + 结构化文本编辑 + 共用排版结果：推荐。保留现有画布，集中升级文字选择、编辑会话、段落布局与导出。
3. 全面复刻专业排版软件：包含路径文字、竖排、完整 OpenType 等，超出现有 F14 边界。暂缓，不妨碍先做好海报标题和正文。

## 推荐操作规则

### 创建与选择

- T 激活文字工具；点击空白处创建点文字，立即出现光标，适合标题和短句。
- 拖出矩形创建段落文字，固定框宽自动换行，溢出显示标记，原文完整保留。
- 每次新建生成独立文字图层，使用 T 标识，默认用内容摘要命名；已有手工名称不随内容被覆盖。
- 点击已有文字选择该对象；文字工具点击可定位插入点，移动工具双击进入编辑。图层面板双击 T 标识进入编辑，名称区域继续用于重命名。
- 空白新对象未输入即取消时不留下占位对象或多余历史。

### 编辑状态与样式

- 明确区分工具默认值、选中对象和文字范围。无对象时设置下次创建样式；选中对象时修改整段；编辑中有范围时仅修改范围，无范围时设置后续输入样式。
- Enter 换行，Ctrl/Cmd+Enter 或「完成」提交；Esc 取消本次会话；中文组字时不触发提交或全局快捷键。
- 点击属于文字工具的字体、颜色、字号控件时保留逻辑文字范围，完成后可回到原插入点；仅靠 textarea 失焦不能界定会话结束。
- 有真实富文本能力的 DOM 编辑器负责输入、选区、粘贴和 IME；结构化段落/样式区间是保存的数据，不存任意 HTML。具体依赖在实施前按 IME、许可和可维护性验证后确定。
- 编辑期间支持本地撤销；一次连续输入/一次参数拖动按事务合并，不能每个字符保存整份文档快照；完成、取消和跨文档切换具有明确边界。

### 排版与变换

- 点文字根据内容自动扩展，不自动按框宽换行；段落文字按框宽排版。
- 拖段落边框改变排版区域，不改变字号；自由变换等比缩放文字作为另一个明确模式，支持旋转、撤销和恢复。
- 第一批排版支持字体、真实字体样式、字号、颜色、行距、字距、段落对齐、文字框宽高与溢出提示。
- 选中字符修改样式；混合样式时面板显示「混合」，不把整段错误显示为某一个字号或颜色。
- 中文标点避头尾、组合字符、emoji、长英文和显式换行进入布局测试。
- 统一测量与布局模块输出行、基线、样式区间和字符位置，编辑命中、画布显示和导出复用其语义。先消除现有 1.2/1.4 行距和锚点差异。
- 本机字体读取走 Tauri 原生枚举，按真实 family/face 提供字重；浏览器预览降级时明确检测状态。优先推荐经过许可核对的开放字体，任意系统字体不自动标为可商用。
- 字体缺失提示替代字体；项目保存所选字体标识和排版数据。导出前等待字体就绪；字体资源使用受许可约束，不静默打包用户字体，也不靠编辑器屏幕截图替代可编辑数据。

## 界面建议

继续现有深色工作室和 24px 紧凑控件，不增加常驻第三面板。

顶部文字选项条：`[字体搜索] [字体样式] [字号] [颜色] [左/中/右对齐] [更多] · [取消] [完成]`。

右侧现有「属性」随选中对象显示：

- 字符：行距、字距、局部样式混合状态。
- 段落：点文字/段落类型、文字框尺寸、对齐及溢出状态。
- 变换：X/Y、旋转、等比变换。
- 效果：F15 能力就绪后接描边、阴影；折叠呈现。

字体选择支持搜索、中文/西文/等宽分类、最近使用及实际字体预览。默认优先显示已安装字体，避免用户反复选择实际不存在的预设。

## 实施顺序和验收

1. 编辑基础：独立文字图层、对象选择、点击立即输入、参数绑定、换行/提交/取消。验收：创建标题后再修改字号和颜色确实改变标题，单独移动/删除文字不改变背景图。
2. 排版基础：段落框、行距字距、宽度重排、文字边界和共用布局。验收：同一中英混排样例在多种缩放、旋转和导出下位置一致，框溢出不丢内容。
3. 专业编辑：局部字体/颜色/字重、选区保持、字体枚举及缺失反馈、IME 和 Unicode。验收：只选中「春日」改色，其他字不变；中文候选确认不误结束会话，编辑可撤销/取消。
4. 项目和效果闭环：数据迁移、离线保存重开、导出字体与排版对照、F15 文字效果。验收：保存重开仍可逐字编辑，导出没有输入框或选择边界。

步骤是推荐工作顺序，不代表已开始执行。原 F14/F15 依赖及人工验收继续有效；不能仅因按钮存在或组件测试通过就宣称文字能力完整。
