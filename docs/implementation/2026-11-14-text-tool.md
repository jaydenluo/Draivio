# Photoshop 式文字工具实现说明

## 已实现

- 使用文字工具在画布点击创建点文字，拖动创建段落文字框。
- 每个文字对象都会创建独立的 `kind: text` 图层，并通过 `textObjectId` 关联到 `canvasTexts`。
- 创建后自动进入编辑状态；双击已有文字可以编辑，Enter 提交，Escape 取消。
- 选中文字图层后可直接拖动移动，使用八个控制点缩放，使用顶部控制点旋转。
- 右侧“属性”面板提供内容、系统字体、字重、字号、颜色、对齐、点/段落类型、行高、字距、位置、尺寸和旋转编辑。
- SVG 场景导出会保留文字的字体、颜色、字重、字距、行高、段落换行和旋转。
- 删除和复制文字图层时，会同步清理或复制关联的文字对象。

## 操作约定

- 选取工具下，单击已选中文字并拖动可移动；单击控制点进入缩放；旋转控制点位于文字框上方。
- 点文字的宽高由文字内容决定；段落文字保留可调整的文字框宽高。
- 文字属性更新会立即写入文档历史，因此可以使用画布底部的撤销/重做恢复。
- 字体使用用户系统已安装的字体名称，应用不打包字体文件；预设字体均为 SIL OFL 1.1 字体名称。

## 编辑模式视觉规则

- 文字工具进入编辑时隐藏普通选区覆盖层，避免红色选区框和文字编辑框重叠。
- 点文字编辑框使用文字内容的自然宽度；段落文字编辑框使用用户创建的文字框宽度和高度。
- 编辑输入框不使用浏览器默认的深色背景和右下角 resize 手柄，只保留轻量边框与文字光标，让输入看起来属于画布。
- 选取工具负责移动、缩放和旋转；文字工具负责进入编辑。两种状态分离，避免拖动文字时意外进入输入状态。
- 新建文字会自动选中占位内容；重新编辑已有文字时光标放在文字末尾。
- 段落文字在输入框中按 Enter 换行，使用 Ctrl/Cmd+Enter 提交；点文字保留 Enter 快速提交。
- 多行输入框会根据内容高度增长，减少文字被输入框裁切的情况。

## 当前边界

尚未实现文字沿路径、OpenType 可变轴、连字细节控制、多文字对象合并为一个图层，以及完整的段落排版规则。段落换行目前使用字体大小估算字符宽度，最终显示以系统字体的实际度量为准。
