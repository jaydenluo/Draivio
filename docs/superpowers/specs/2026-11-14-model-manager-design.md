# 模型按需安装与后台下载设计

## 目标

为扣图和超分提供独立工具入口。工具入口始终可见，模型按需安装，支持后台下载、断点续传、暂停/继续、失败重试和完整性校验，同时避免把大模型打进应用安装包。

## 范围

首期支持以下可选模型：

- 扣图：U2Net、U2Netp、RMBG-2.0
- 超分：Real-ESRGAN x4plus、Real-ESRGAN anime

首期只实现模型资源管理与工具安装引导；实际推理调用通过稳定接口接入，后续可以分别绑定本地推理或其他执行器。

## 架构

React 前端提供 Model Manager 状态层和模型管理 UI。工具通过 `ensureModelInstalled(modelId)` 请求模型，不直接读写下载状态或文件。

Tauri/Rust 负责模型目录、后台 HTTP 下载、HTTP Range 续传、重试、临时文件、磁盘空间检查、SHA256 校验和原子安装。浏览器开发环境提供可替换的内存/本地模拟实现，用于组件测试。

模型 manifest 版本化管理以下字段：模型 ID、版本、显示名称、用途、文件大小、所需空间、SHA256、下载地址列表、运行时要求、许可证链接和兼容平台。

模型保存于应用数据目录，路径按模型 ID 和版本隔离。下载写入临时文件，校验成功后原子改名为已安装文件；应用更新不应删除已安装模型。

## 状态机

正常流程：

`uninstalled -> queued -> downloading -> verifying -> installed`

可恢复状态：`paused`、`failed`、`outdated`。

下载任务以模型 ID 去重；应用重启后从持久化的临时文件大小恢复 Range 请求。网络失败自动重试，超过上限后进入 `failed` 并保留可续传文件。

## 用户流程

1. 扣图或超分入口始终显示。
2. 点击未安装的工具后，弹窗列出适用模型、效果说明、下载大小、空间需求和许可证入口。
3. 用户选择模型并开始安装；任务立即进入后台，关闭弹窗不会中断任务。
4. 工具入口和模型管理页显示进度、速度、暂停/继续/取消和错误信息。
5. 下载完成后自动校验；校验成功后模型变为可用并返回工具。
6. 用户可以在模型管理页切换已安装模型或删除可恢复的模型文件。

## 错误处理

- 下载地址失败：按地址顺序尝试镜像并自动重试。
- 不支持 Range：删除当前临时文件后重新开始，并在 UI 中说明。
- 磁盘空间不足：下载前阻止任务并显示所需空间。
- SHA256 不匹配：保留失败记录，允许重新校验或重新下载。
- 推理执行失败：与模型安装错误分开显示，保留模型状态。

## 验收标准

- 未安装模型不会被静默下载。
- 用户可以从工具入口选择模型并开始后台安装。
- 下载中关闭弹窗后任务仍继续。
- 网络中断或应用重启后可以从已有字节继续下载。
- 下载完成后必须通过 SHA256 校验才显示为已安装。
- 重复点击安装不会创建重复任务。
- 工具能明确显示未安装、下载中、失败和已安装状态。
- 模型文件不写入应用安装目录，也不会随普通应用更新删除。

## 测试

- Range 续传、暂停/恢复、重试、校验失败和任务去重测试。
- Model Manager UI 状态和弹窗交互测试。
- Tauri 下载命令的路径隔离、临时文件和 SHA256 测试。
- 运行项目现有的 `npm test` 和 `npm run build`。

## 风险与后续

- RMBG-2.0 的模型许可需要在商业发布前单独核对。
- 不同平台的后台下载和应用休眠行为需要真机验证。
- 本期不包含实际推理引擎、在线自动更新、云端推理或 GPU/CPU 自动调优。
