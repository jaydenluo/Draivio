# OpenAI 图片批量生成

用户已批准上一轮建议并授权实现。界面保持紧凑，不增加第二个生成按钮。

服务来源可配置单次多图/分次生成、并发上限（1–4，默认2）、是否发送分辨率、画质（不发送/auto/low/medium/high）。模型可覆盖来源默认；旧配置默认单次多图、发送尺寸、不发送画质。分次生成省略 n（官方默认1），提高中转兼容性；单次多图发送 n=N。

OpenAI Images 和火山兼容 Images 使用真实文生图 POST；其他协议和真实图片编辑明确拒绝，不发送不完整请求。云端仍使用既有演示。浏览器直接请求（受 CORS 限制），桌面经 Rust reqwest。密钥不进入编辑器、历史或任务状态。支持 URL/base64 图片，逐张加入结果和画布。

队列状态：排队、执行中、成功、失败、结果未知、未返回、已取消。默认最多2个并行；429 后降为1并按 Retry-After 冷却（上限60秒），不自动重发已失败请求。每个批次冻结提示词/模型/参数。取消仅停止未发送请求，保留已提交结果。单次返回少图保留已有图，不静默补发。明确失败、未返回和未发送项可由用户手动补齐；超时/网络错误/响应异常属于结果未知，须额外确认可能重复计费后重新生成。

生成入口共享任务与取消/重试状态，不重复提交。重新尝试前读取当前仍启用的来源密钥，模型/参数仍使用原批次快照。只验证模拟服务器/桩，不实际调用付费供应商。
