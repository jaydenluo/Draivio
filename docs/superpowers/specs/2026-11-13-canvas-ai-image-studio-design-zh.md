# 画布式 AI 图片创作软件设计

## 1. 产品目标

打造一款开源的桌面图片创作与编辑软件，首发支持 Windows 和 macOS。产品以画布为核心，用户可以手绘、上传图片、输入提示词、选择区域，并直接在画布上使用 AI 能力。

软件支持两种模型使用方式：

- **官方云服务**：用户登录你的服务，使用账户余额或额度。
- **用户 API Key**：用户配置自己的模型服务商密钥，由桌面端直接调用第三方服务，密钥保存在本地 SQLite 中，明文保存并允许用户查看。

软件不在本地运行模型，不下载模型权重，第一版也不提供用户可见的节点图。

## 2. 产品原则

1. **先画布，后配置**：用户可以先画图或上传图片，再考虑模型、供应商和高级参数。
2. **AI 操作围绕当前画布**：操作自动使用当前画布、图层、选区、蒙版、参考图和提示词。
3. **一次操作产生一组结果**：生成、局部重绘、抠图和放大应返回可预览的结果，用户可以接受、拒绝或继续编辑。
4. **非破坏式历史**：每次 AI 请求和画布编辑都记录下来，支持撤销、比较、重试和恢复旧版本。
5. **模型供应商无关**：编辑器不应依赖某一家模型厂商的请求格式。
6. **默认简单，高级信息按需显示**：模型、种子、比例和费用等信息可以查看，但不能干扰主画布。

## 3. 用户体验

### 3.1 主工作区

主窗口采用四区布局。它保留专业编辑需要的工具和图层，同时控制每个区域的职责，避免把模型控制台直接铺满屏幕。

```text
┌──────────────────────────────────────────────────────────────┐
│ Logo  项目名 / 未保存       撤销 重做       云端/API 余额 导出 │  52px
├──────┬───────────────────────────────────────┬───────────────┤
│      │                                       │               │
│ 工具 │                                       │ 生成 / 编辑    │
│ 栏   │              主画布                   │ 图层 / 参数    │
│ 64px │        图片、手绘、选区、蒙版          │ 320px          │
│      │                                       │               │
├──────┴───────────────────────────────────────┴───────────────┤
│ 操作历史 / 生成结果缩略图 / 多结果对比                         │ 128px
└──────────────────────────────────────────────────────────────┘
```

- **顶部项目栏**：项目名、保存状态、撤销/重做、云端/API 状态、余额和导出。
- **左侧工具栏**：选择、移动、画笔、橡皮擦、矩形/椭圆选区、套索、蒙版、裁剪、文字、取色器和画布平移。
- **中央画布**：图层内容、缩放、平移、辅助线、选区、蒙版和前后对比。画布区域在宽窗口中占可用宽度的 60% 以上。
- **右侧操作面板**：生成、编辑、图层三个标签。生成和编辑显示提示词及常用参数，图层显示图层列表和基本属性。
- **底部历史栏**：最近操作、生成结果、多结果对比、重试和恢复。高度固定为 128px，避免遮挡画布。

### 3.2 核心操作

- **草图生成**：用户画一个简单草图，输入描述，生成受草图约束的图片。
- **文生图**：用户输入提示词，在新图层或新文档中生成图片。
- **图生图**：用户选择一张图片，调整变化强度并输入提示词。
- **局部重绘**：用户绘制蒙版或创建选区，输入修改要求，只替换选中的区域。
- **抠图/移除背景**：将主体从背景中分离，生成透明图层或透明图片。
- **放大**：对选中的图层或图片进行放大，并选择尺寸和质量模式。

这些都是直接作用于画布的操作，不是用户需要添加和连接的节点。

### 3.3 项目与历史

项目需要保存：

- 画布尺寸、色彩设置和图层结构；
- 栅格图层和蒙版；
- 提示词、供应商、模型、参数和操作时间；
- 生成的素材及其来源操作；
- 可以恢复旧状态的版本历史。

第一版采用文件夹式项目格式：一个版本化的 JSON 清单，加一个素材目录。清单必须带版本号，方便以后迁移旧项目。

生成图片只保存在本地项目目录或用户选择的本地素材目录中。默认不把最终图片同步到官方云服务。

### 3.4 四区布局的交互规则

- 右侧面板默认打开“生成”标签，因为它是最常用的 AI 操作入口。
- 用户在画布中创建选区或蒙版后，右侧面板自动切换到“编辑”标签，并保留已输入的提示词。
- 用户点击某个图层后，右侧面板可以切换到“图层”标签；切换标签不会清除当前生成参数。
- 右侧面板顶部显示当前操作类型，底部固定显示主要按钮和预计费用。
- 左侧工具栏只负责画布工具，不放模型、余额和账户入口。
- 底部历史栏显示结果缩略图；选择缩略图只改变预览，点击“应用”后才写入当前图层或新图层。
- 窗口宽度低于 1180px 时，右侧面板可以收窄到 280px；低于 960px 时，右侧面板变成从右侧滑出的抽屉，中央画布保留最小可编辑宽度。

## 4. 内部架构

### 4.1 桌面端技术栈

- **Tauri 2**：桌面壳和原生能力。
- **React + TypeScript**：界面和应用状态。
- **Konva**：画布、选区、蒙版和图层交互。第一版由应用自己维护图层模型，Konva 的场景图和 React 集成已经足够。
- **Rust Commands**：文件系统、原生对话框、SQLite 文件位置和受控的网络/文件操作。
- **TypeScript 操作控制器**：编辑器操作、请求准备、任务轮询和结果插入。

Rust 层保持精简。渲染、供应商请求转换和编辑器行为放在 TypeScript 中，只有原生能力才放到 Rust。

### 4.2 操作模型

软件内部使用统一的“操作协议”，而不是节点协议。每个操作声明输入、模型能力、参数、输出素材、状态和费用信息。

```ts
type ImageOperation = {
  id: string
  type: "text_to_image" | "sketch_to_image" | "image_to_image" |
    "inpaint" | "remove_background" | "upscale"
  inputAssetIds: string[]
  maskAssetId?: string
  prompt?: string
  parameters: Record<string, unknown>
  providerId: string
  status: "queued" | "running" | "succeeded" | "failed" | "cancelled"
  outputAssetIds: string[]
  createdAt: string
}
```

这个模型支持撤销、重试、费用显示和版本恢复，用户不需要理解节点图。

### 4.3 模型供应商适配层

编辑器通过统一的供应商适配器接口调用模型：

```ts
type ImageProvider = {
  id: string
  name: string
  authMode: "managed_cloud" | "user_api_key"
  capabilities: string[]
  createJob(input: ImageJobInput): Promise<{ jobId: string }>
  getJobStatus(jobId: string): Promise<JobStatus>
  cancelJob(jobId: string): Promise<void>
}
```

第一版可以支持：

- 你的官方云服务；
- OpenAI Images；
- Stability AI；
- Replicate 或其他稳定的 REST 图像服务；
- 在能力匹配时支持可配置的 OpenAI-compatible 图像接口。

适配器负责把统一操作转换成供应商请求，再把供应商返回结果转换成统一格式。不支持的参数必须隐藏或明确标记为不支持，不能静默忽略。

### 4.4 密钥与隐私

- 官方云服务的登录令牌可以通过 Tauri 的本地应用数据目录保存，并按登录会话管理。
- 用户 API Key 使用本地 SQLite 数据库保存，字段包括供应商、名称、Base URL、API Key、启用状态和创建时间。
- API Key 按你的要求明文保存，并在设置页提供查看、复制、修改和删除功能。
- SQLite 数据库放在 Tauri 的应用数据目录中，例如 macOS 的 Application Support 和 Windows 的 AppData。项目清单、操作历史、图片文件和日志中不重复写入 API Key。
- 明文 SQLite 意味着拥有本机账户权限的程序可能读取这些密钥；设置页应明确提示这个风险，但不额外引入加密或系统密钥链作为强制依赖。
- 用户 API Key 模式下，图片请求由桌面端直接发送给供应商。官方云模式下，桌面端只把请求发送给你的云服务。

## 5. 官方云服务

官方云服务使用现有目录 `/Users/szys/AI/video-maker/cloud`。该服务已经提供账户、模型目录、余额、计费和统一模型网关，桌面端优先复用现有 API，而不是在客户端重新实现一套云端协议。

第一版桌面端需要对接的主要接口是：

- `GET /api/auth/me`：获取当前登录用户；
- `POST /api/auth/password-login` 或邮箱验证码登录接口：桌面端登录；
- `POST /api/auth/refresh`：刷新桌面会话；
- `GET /api/model-gateway/v1/models`：读取可用图片模型、能力和约束；
- `GET /api/model-gateway/v1/balance`：读取账户余额；
- `POST /api/model-gateway/v1/images/generations`：文生图和草图生成；
- `POST /api/model-gateway/v1/images/edits`：图生图、局部重绘和蒙版编辑；
- `POST /api/model-gateway/v1/quotes`：提交前获取报价；
- 账户充值和用量查询接口：显示余额变化和消费明细。

请求统一携带 `Authorization: Bearer <accessToken>`、`X-MOVIVIZ-Client: desktop` 和每次付费操作唯一的 `Idempotency-Key`。模型参数使用云服务返回的平台模型 `code`，不直接暴露供应商模型 ID。

云服务建议拆成以下边界：

- 用户身份和账户服务；
- 充值、余额和用量账本；
- 模型供应商网关和路由；
- 异步任务服务；
- 任务临时状态和可选的短期缓存；
- 限流、退款、滥用防护和供应商故障处理。

官方云生成图片的保存策略需要与现有媒体存储逻辑区分：云服务可以在任务执行期间临时取得上游图片，但完成后只把图片内容返回给桌面端，桌面端下载并写入本地项目。最终图片不进入用户的云端项目库；如果服务端因为供应商返回 URL 而产生临时文件，应设置短期过期清理，不作为长期素材保存。

每个计费请求都要有幂等键。账本记录预扣、实际消耗、退款和过期额度。供应商任务失败时不能默认扣除全部费用，必须定义退款或部分扣费规则。

如果供应商可以估算费用，客户端应在提交前展示预估价格。完成后记录实际消耗和供应商请求 ID。

## 6. 开源边界

建议拆分为以下仓库或目录：

- `desktop`：Tauri 桌面应用；
- `operation-schema`：版本化的操作和项目数据结构；
- `provider-sdk`：适配器接口和社区适配器；
- `cloud-gateway`：可部署的云端网关参考实现；
- `cloud-console`：账户、余额、用量和运营控制台。

客户端、数据结构和 SDK 建议完全开源。你的官方服务可以运行同一套网关，同时将支付、风控、供应商合同和生产基础设施独立管理。

### 后续版本

## 8. 主要风险与应对

- **供应商差异**：通过能力发现机制隐藏不支持的控件。
- **任务耗时或失败**：使用异步任务状态机，支持取消、重试、超时和幂等。
- **云端计费争议**：展示预估费用，执行前预扣额度，并保留完整用量账本。
- **项目文件过大**：素材与清单分开保存，生成缩略图，并提供缓存清理。
- **画布性能**：预览分辨率与导出分辨率分离，耗时的图片处理放到 UI 线程之外。
- **明文密钥泄露**：SQLite 明文符合当前产品要求，但本机其他程序可能读取；设置页必须展示风险提示，日志和项目文件仍不得记录密钥。
- **云端图片残留**：官方云服务只允许短期任务缓存，生成完成后由桌面端下载并保存，服务端定期清理临时文件。

## 9. 成功标准

第一版成功的标准是：新用户可以创建项目，手绘或上传图片，运行 AI 操作，比较多个结果，继续在画布上编辑，并导出最终图片；整个过程不需要看节点图，也不需要学习供应商专属的请求格式。

同时，技术用户可以配置自己的 API Key 或使用官方云服务，并能清楚看到费用、任务状态和错误信息。

## 10. 前端视觉设计

### 10.1 视觉方向

前端采用“安静的深色工作区 + 明亮的纸张画布 + 手绘珊瑚色动作”的方向。最终采用四区专业编辑布局：工具栏、画布、右侧操作面板和底部历史栏同时存在，但每个区域只承担单一职责。

核心识别元素是一条短的珊瑚色手绘线：用于主生成按钮的左侧标记、选区边缘和空白状态插图。它只在关键动作附近出现，不作为背景装饰。

### 10.2 颜色令牌

```css
:root {
  --ink-950: #0d1013;       /* 画布外围 */
  --ink-900: #15181c;       /* 应用背景 */
  --ink-850: #1c2127;       /* 浮层和创作胶囊 */
  --ink-800: #252c33;       /* 悬浮和输入区域 */
  --ink-700: #303841;       /* 分隔线 */
  --paper-50: #f4f1eb;      /* 画布背景 */
  --text-strong: #f2efe8;   /* 主文字 */
  --text-muted: #9ca6af;    /* 次要文字 */
  --text-faint: #69737d;    /* 辅助文字 */
  --coral-500: #ff765f;     /* 生成主动作 */
  --coral-400: #ff907d;     /* 主动作悬浮 */
  --sky-400: #77c7ff;       /* 选区、参考线 */
  --mint-400: #80d6a5;      /* 成功 */
  --amber-400: #f0c36a;     /* 警告 */
  --red-400: #f27c7c;       /* 错误 */
}
```

画布内容区使用 `--paper-50` 或用户图片本身的颜色，画布外部使用 `--ink-950`，避免图片边界与应用 chrome 混在一起。输入框、右侧操作面板和底部历史栏使用 `--ink-850`，不使用纯黑色卡片。

### 10.3 字体与层级

- 界面正文使用 `Noto Sans SC`，字重 400/500/600。
- 参数、尺寸、快捷键、费用和任务 ID 使用 `IBM Plex Mono`，字重 400/500。
- 品牌名使用 `Noto Sans SC` 600，不使用装饰性标题字体。

字号层级：

| 用途 | 字号 | 行高 | 字重 |
| --- | ---: | ---: | ---: |
| 页面标题 | 20px | 28px | 600 |
| 区域标题 | 14px | 20px | 600 |
| 正文和按钮 | 13px | 20px | 500 |
| 辅助说明 | 12px | 18px | 400 |
| 参数和快捷键 | 11px | 16px | 500 |

### 10.4 间距、圆角和边框

- 基础间距为 4px，常用间距为 8、12、16、24、32px。
- 顶部栏高度 52px，左侧工具栏宽度 64px，右侧操作面板宽度 320px，底部历史栏高度 128px。
- 右侧面板中的提示词输入区最大高度 160px，生成按钮固定在面板底部可见区域。
- 创作操作卡片圆角 12px，浮层创作胶囊圆角 16px。
- 小型按钮圆角 8px，输入框圆角 10px，项目卡片圆角 12px。
- 画布不加圆角；画布是内容本身，不是卡片。
- 面板边框使用 1px `--ink-700`，不使用厚重阴影。
- 浮层只使用 `0 12px 32px rgba(0, 0, 0, .24)`，避免出现发光效果。

### 10.5 操作状态

主按钮文案必须说明结果：

- `生成图片`
- `生成局部`
- `应用到当前图层`
- `新建图层`
- `保存项目`
- `测试连接`

按钮状态：

- 默认：珊瑚色背景，深色文字。
- 悬浮：背景变为 `--coral-400`，轻微上移 1px。
- 按下：恢复默认色，不改变布局。
- 执行中：按钮文字改为 `生成中…`，右侧显示细线进度，仍可点击取消。
- 禁用：使用 `--ink-700` 背景和 `--text-faint`，同时保留禁用原因的提示。

错误状态使用具体说明：

- `余额不足，充值后再生成`
- `API Key 无效，请检查密钥或 Base URL`
- `当前模型不支持局部重绘`
- `网络连接失败，点击重试`

### 10.6 图标与图形语言

图标使用 16px、1.5px 线宽的单色图标。优先使用 Lucide 一类的几何图标，但需要统一圆角端点。

- 画笔：斜向笔尖。
- 生成：四角星加短线，不使用魔法棒渐变。
- 编辑：选区虚线加画笔。
- 历史：逆时针圆弧。
- 导出：向下箭头进入横线。
- API Key：钥匙轮廓。

左侧工具栏使用图标为主，选中工具时显示珊瑚色短线和悬浮提示；右侧面板和顶部栏使用“图标 + 文字”。撤销、重做、缩放使用纯图标并提供悬浮提示。

### 10.7 动效

动效服务于状态变化，不用于装饰：

- 页面切换：180ms 淡入，内容向上移动 4px。
- 创作胶囊展开：180ms 高度和透明度过渡。
- 结果卡片出现：220ms 从画布右下方向上移动 8px。
- 选区蒙版：使用 1.5s 的低透明度呼吸动画，提示当前选区仍可编辑。
- 生成中：使用连续的 2px 珊瑚色进度线，不旋转大型加载图标。
- 用户开启“减少动态效果”后，所有位移和呼吸动画关闭，只保留颜色变化。

### 10.8 空状态与错误状态

空画布中央显示一张很小的线稿，旁边只有一句话：

> 拖入图片，或先画几笔

下面放两个动作：`新建空白画布`、`打开图片`。不显示长段产品介绍。

空历史显示：

> 生成的结果会出现在这里

余额不足时，创作胶囊保持打开，底部显示余额和两个明确动作：`充值`、`切换 API Key`。API Key 错误时显示 `打开 API Key 设置` 和 `重试连接`。

### 10.9 设计约束

- 中央画布必须占主窗口可用宽度的 60% 以上，右侧面板固定在 320px 左右。
- 常驻主动作集中在顶部栏和右侧面板：返回、撤销、重做、导出、生成。
- 右侧面板允许常驻，但只显示当前标签的内容；生成、编辑和图层不同时展开。
- 底部历史栏固定高度，不因为结果数量增加而挤压画布；更多结果通过横向滚动查看。
- 生成结果永远先以预览出现，用户明确选择后才写入图层。
- 所有操作支持键盘焦点，焦点环使用 `--sky-400`，不能只依赖颜色表达状态。
