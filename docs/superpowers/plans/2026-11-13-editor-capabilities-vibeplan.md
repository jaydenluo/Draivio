## 共同约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。
- 继续“图层 / 属性 / AI 结果”右侧架构；属性随对象变化，常用表单 24px、可键盘操作、中文可理解标签；对话框/顶部放置低频复杂操作，不能全部堆到右侧。
- 无能力、空状态、处理中、部分失败、取消、重试均有真实反馈；工具入口不作为完成证据。
- 单元测试覆盖数据/几何/像素行为，组件测试覆盖关键交互；图像能力增加固定输入与输出对照，真实服务另留授权调用证据。
- 在实施任务前读取最新 Vibe Plan 上下文、上传实施计划；结束记录实际改动、测试命令/退出码、验收逐项证据和未解决问题。通过检查后只进入待验收，不自动通过人工验收。
- 本文是可验收功能定义与工作分解，不是已经完成的代码；不授权自动提交、推送、部署或真实付费调用。

## 技术边界与交付顺序

保持 React + TypeScript 单一文档状态模型，先抽文档/资源与统一合成接口；SVG 可继续承担交互预览，但像素、ICC、高位深不能只靠 CSS filter 宣称实现。Tauri 负责可靠文件系统、必要编解码与色彩/RAW 原生桥接，Web 分支需明确不可用能力。新增路径带 + 表示计划创建，其他为现有接入文件；实施前核实最新结构，避免把所有逻辑继续堆进 editor.tsx。

1. 基础可用：原任务补全（R01–R04）；F04 像素坐标 → F01 项目文件 → F02 恢复、F03 导出。
2. 排版：组与合成、对齐/吸附、文字、效果、路径。
3. 修图和 AI：主体/边缘、修复/移除；真实参考图编辑 → 选区填充 → 扩图。
4. 调色和非破坏：直方图/白平衡 → 曲线/色阶 → HSL/预设 → 调整层、智能对象、智能滤镜。
5. 效率：多文档、多画板、批处理。
6. 专业：ICC 和高位深 → RAW、CMYK → 软打样。专业能力也列入 backlog，但不会阻塞普通 RGB 编辑器首阶段交付。

### R01 补全图层组继承、深复制和锁定保护

**目标：** 修复已有图层基础管理，保持原任务范围。

**范围：** 组隐藏、锁定、透明度完整继承到后代；所有写操作统一校验有效锁定；复制图层/组深复制关联文字、笔画、形状、蒙版，重映射 ID；保持重命名、排序、删除保护、多选、缩略图。

**交互：** 继续使用图层列表和属性区，锁定/继承状态有文字反馈；批量操作明确报告跳过的锁定对象。

**初始拆解估算：** 5 天（不覆盖原任务 estimate）。

**相关文件：** src/state/editor.tsx、src/state/layerWorkspace.test.ts、src/layers/LayersPanel.tsx、src/canvas/CanvasScene.tsx。

**必须补交的验收证据：**

- [ ] 两级组隐藏/锁定/透明度在画布、缩略图、导出一致；子层不能绕过祖先锁定。
- [ ] 复制含文字、笔画、形状和蒙版的组，修改副本不影响原件，引用 ID 无悬空或重用。
- [ ] 移动、属性、画笔、蒙版、删除、合并、AI 替换均覆盖锁定校验；撤销能完整恢复。

**验收映射：** 原任务第 2、5、7 条。

### R02 统一历史快照和撤销/重做

**目标：** 让历史列表与实际文档状态一致，而不是只恢复图片缩略图。

**范围：** 历史记录绑定同一文档版本快照；覆盖对象、蒙版、参数、选区、资源引用；连续拖拽/输入合并为事务；恢复后新编辑清除 redo 分支；限制快照内存并保护活跃资源。

**交互：** 历史列表展示动作和缩略图，点击明确恢复该版本；拖动一次仅一个历史项，保存状态按文档版本计算。

**初始拆解估算：** 5 天（不覆盖原任务 estimate）。

**相关文件：** src/state/editor.tsx、src/state/layerWorkspace.test.ts、src/canvas/CanvasViewport.tsx。

**必须补交的验收证据：**

- [ ] 混合操作后从历史跳到任一版本，图层树、文字、笔画、蒙版、调整与该快照一致。
- [ ] 撤销/重做和历史点击使用同一版本序列；恢复后新编辑不能重做已分叉内容。
- [ ] 限制历史不释放当前或仍可撤销状态引用的图片；长拖动和滑块只生成一次提交。

**验收映射：** 原任务第 2、3、4、6、7 条中的撤销/历史一致性。

### R03 统一 AI 候选、比较和采用流程

**目标：** 修复真实与模拟生成路径混用正式图层的问题，落实已有候选工作流。

**范围：** 真实和模拟都先创建独立候选；保存 batchId、source/thumbnail、参数、采用关系；筛选本次/已采用/未采用；2–4 格比较、继续编辑、收藏删除；新增或替换才写正式图层，替换可撤销。

**交互：** 沿用“AI 结果”标签和现有紧凑操作区；候选成功不自动抢焦点或替换当前对象；无可用候选时准确提示。

**初始拆解估算：** 5 天（不覆盖原任务 estimate）。

**相关文件：** src/creation/ImageGeneration.tsx、src/layers/ResultsPanel.tsx、src/state/editor.tsx、src/creation/InspectorWorkspace.test.tsx。

**必须补交的验收证据：**

- [ ] 真实适配器返回图片后正式层数量不变，点击新增才创建独立图层；模拟路径行为相同。
- [ ] 替换保留原始内容并可撤销，锁定目标拒绝替换；删除候选不删除已采用图层。
- [ ] 本次筛选按实际 batchId，比较展示真实 source；继续编辑恢复输入和参数，失败/部分成功无空白占位层。

**验收映射：** 原任务第 4、5、7、8 条。

**交互：** 保留默认展开、两列四行的基础调整，控件 24px；预览开关、单位和重置清楚，不增加统一 AI 强度。

**初始拆解估算：** 6 天（不覆盖原任务 estimate）。

**相关文件：** src/canvas/CanvasScene.tsx、src/canvas/documentIO.ts、src/layers/PropertiesPanel.tsx、src/state/layerWorkspace.test.ts。
