# F21 减淡、加深与局部色调画笔

**目标：** 精修局部明暗而不直接破坏原始照片。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 5 天 / 无截止日期 / 不预设负责人。

**阶段：** 3；**依赖：** F11, F16。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

减淡/加深画笔，选择阴影/中间调/高光、曝光强度、笔刷硬度/流量，保护色调；输出为可编辑的局部调整蒙版或专用处理层。

## 入口与交互

修图工具组选择减淡/加深，顶部显示作用范围与强度；属性可调累计效果及蒙版。

## 范围边界

此强度是画笔曝光量，与 AI 模型 strength 无关，UI 标签明确。
