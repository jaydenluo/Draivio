# F19 污点修复、仿制与修补工具完整闭环

**目标：** 清理污点和纹理瑕疵，支持本地编辑和明确的服务修复。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 8 天 / 无截止日期 / 不预设负责人。

**阶段：** 3；**依赖：** F01, F04, R01。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

仿制源点、对齐/非对齐、画笔硬度/透明度；污点修复支持小范围纹理融合；修补以选区和目标偏移重建；采样当前层/当前及下方/所有可见，默认输出新修复层。

## 入口与交互

修图工具组顶部显示采样、大小、硬度；Alt 点击设仿制源，源点预览；修补拖动目标后确认/取消。

## 范围边界

大型语义对象移除归 F20；本地算法与远程服务标明来源，无服务不假成功。

## 数据、可靠性与界面约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。
- 继续“图层 / 属性 / AI 结果”右侧架构；属性随对象变化，常用表单 24px、可键盘操作、中文可理解标签；对话框/顶部放置低频复杂操作，不能全部堆到右侧。
- 无能力、空状态、处理中、部分失败、取消、重试均有真实反馈；工具入口不作为完成证据。
- 单元测试覆盖数据/几何/像素行为，组件测试覆盖关键交互；图像能力增加固定输入与输出对照，真实服务另留授权调用证据。

## 验收标准与验证样例

1. 固定纹理、皮肤小斑点和边缘样例验证源点偏移及融合，不仅生成一条颜色笔画。
2. 采样范围与隐藏层规则正确；输出新层保留原图，祖先锁定不改受保护内容。
3. 一次笔画/修补一次撤销，取消中途请求不产生半成品层。
4. 高缩放、旋转视图与非默认画布尺寸下采样坐标正确；断网服务分支给具体原因。
