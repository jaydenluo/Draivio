# F32 CMYK 文档与印刷导出

**目标：** 支持有配置文件约束的印刷输出，并保留可理解的模式转换。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 15 天 / 无截止日期 / 不预设负责人。

**阶段：** 6；**依赖：** F30, F31。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

建立真正的 CMYK 文档像素和颜色类型、配置文件转换、总墨量检查、CMYK 数值输入；定义 RGB 专属效果在 CMYK 中的禁用或明确转换策略；输出带 ICC 的 CMYK TIFF。

## 入口与交互

文档模式提供 RGB/CMYK 转换并预览；颜色输入随文档显示通道；导出标明 CMYK、ICC、位深和总墨量预警。

## 范围边界

不包含专色、多通道和 PDF/X 印前生产；不能只把 RGB 四个字段命名为 CMYK。

## 数据、可靠性与界面约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。

## 验收标准与验证样例

1. CMYK TIFF 经独立解码验证四通道和嵌入 profile，纯黑和总墨量样例符合所选印刷 profile。
2. RGB↔CMYK 通过 ICC 转换，超色域与可能有损反馈明确，转换可撤销且保留源。
3. CMYK 项目重开保持通道，预览、软打样接口与导出不出现二次转换。
4. 不支持的滤镜/AI 接口需显式生成 RGB 副本，不静默更改文档模式。
