# F27 多画板与同设计多尺寸版本

**目标：** 在同一项目组织多个尺寸方案，并逐画板导出。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 8 天 / 无截止日期 / 不预设负责人。

**阶段：** 5；**依赖：** F26, F08, F03。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

画板有 ID、名称、尺寸、位置、背景和所属图层；移动/复制/排序；创建常用规格变体，复制设计时可选等比缩放或保持对象尺寸；共享智能对象素材可复用。

## 入口与交互

画布显示画板边框和名称；图层按画板分组；顶栏画板切换及导出所选/全部画板。

## 范围边界

首版不自动智能重排版；不同尺寸版本创建后独立编辑，除共享智能对象内容外不隐式联动。

## 数据、可靠性与界面约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。

## 验收标准与验证样例

1. 画板之间选区/裁切/吸附正确，移动画板携带内容且不改变局部坐标。
2. 复制为不同规格时用户能预览缩放或裁切结果，不静默丢层。
3. 全部画板导出分别具备正确像素尺寸/名称，重名处理不覆盖。
4. 画板增删、跨板移动、撤销和项目重开恢复一致，空画板可保留。
