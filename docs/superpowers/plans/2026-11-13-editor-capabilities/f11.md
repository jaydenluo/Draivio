# F11 直方图、曝光与准确白平衡

**目标：** 用可解释的直方图和色彩参数调整照片，避免色温只是简单叠色。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 5 天 / 无截止日期 / 不预设负责人。

**阶段：** 4；**依赖：** F03, R04。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

提供 RGB/亮度直方图、曝光 EV、色温与色调、白平衡取样、剪裁警告；在明确线性/显示色空间步骤中计算；位深升级后保持一致接口。

## 入口与交互

图片属性“图像调整”保留紧凑基础区，展开高级区显示直方图与曝光/白平衡；取样时显示操作提示和取消方式。

## 范围边界

不把普通 JPEG 色温伪装为可恢复 RAW 拍摄白平衡；RAW 解码另立任务。

- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。

## 验收标准与验证样例

1. 灰阶与已知色卡验证曝光一档的线性光关系及中性灰白平衡，默认参数输出不变。
2. 直方图正确统计透明与选区范围，剪裁警告仅叠加预览不进入导出。
3. 参数与取样结果可撤销、重置、保存并导出一致。
4. 拖动参数不阻塞输入，旧直方图计算结果不覆盖最新预览。
