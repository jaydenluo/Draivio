# F01 建立可恢复编辑状态的 Draivio 项目文件

**目标：** 让用户保存并重新打开完整作品，继续编辑而不是只得到一张扁平图片。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 8 天 / 无截止日期 / 不预设负责人。

**阶段：** 1；**依赖：** 无。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

定义带 schemaVersion 的项目容器、文档 ID、像素尺寸、资源索引及校验；保存图层树、文字、笔画、形状、蒙版、调整和 AI 来源元数据；本地资源内嵌或打包，远程临时 URL 转为持久资源；提供旧版本迁移和另存为。

## 入口与交互

顶栏“新建 / 打开 / 保存 / 另存为”；显示真实项目名及未保存标记；Cmd/Ctrl+S 保存，关闭脏文档提供保存/放弃/取消。

## 范围边界

不包含 PSD 双向兼容；不保存 API 密钥、请求凭据或浏览器对象 URL；每项后续能力自行扩展序列化及迁移。

## 数据、可靠性与界面约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。
- 继续“图层 / 属性 / AI 结果”右侧架构；属性随对象变化，常用表单 24px、可键盘操作、中文可理解标签；对话框/顶部放置低频复杂操作，不能全部堆到右侧。
- 无能力、空状态、处理中、部分失败、取消、重试均有真实反馈；工具入口不作为完成证据。
- 单元测试覆盖数据/几何/像素行为，组件测试覆盖关键交互；图像能力增加固定输入与输出对照，真实服务另留授权调用证据。
- 在实施任务前读取最新 Vibe Plan 上下文、上传实施计划；结束记录实际改动、测试命令/退出码、验收逐项证据和未解决问题。通过检查后只进入待验收，不自动通过人工验收。
- 本文是可验收功能定义与工作分解，不是已经完成的代码；不授权自动提交、推送、部署或真实付费调用。

## 验收标准与验证样例

1. 含图片、文字、笔画、形状、蒙版、分组、调整及 AI 结果的项目离线重开后仍可分别编辑，内容和层级一致。
2. 保存采用临时文件加原子替换；模拟写入失败仍保留原文件，未保存标记不被清除。
3. 损坏文件、缺失资源、较新版本均给出具体错误且不覆盖当前作品；支持至少一个旧 schema 迁移样例。
4. 打开/另存为/关闭的取消分支不丢作品；保存不包含密钥，资源路径限制在容器内。
5. 验证项目往返、资源去重、无网重开和脏状态；记录实际样例文件与重开截图。
