# F20 移除工具与内容识别填充

**目标：** 移除画面中的不需要对象，并可控制用于补洞的采样区域。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 8 天 / 无截止日期 / 不预设负责人。

**阶段：** 3；**依赖：** F19, F10。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

移除画笔、选区内容识别填充、自动/手动采样区域、保护区域；本地补洞或已配置服务各自明确；结果输出新层供前后比较。

## 入口与交互

选区上下文菜单“内容识别填充”；临时工作区显示待填区域与采样覆盖，可调整后预览、确认或取消。

## 范围边界

生成式语义补全使用 AI 适配器任务 F24；本项不把本地填补质量包装成理解物体。

## 数据、可靠性与界面约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。
- 继续“图层 / 属性 / AI 结果”右侧架构；属性随对象变化，常用表单 24px、可键盘操作、中文可理解标签；对话框/顶部放置低频复杂操作，不能全部堆到右侧。
- 无能力、空状态、处理中、部分失败、取消、重试均有真实反馈；工具入口不作为完成证据。
- 单元测试覆盖数据/几何/像素行为，组件测试覆盖关键交互；图像能力增加固定输入与输出对照，真实服务另留授权调用证据。

1. 重复纹理、天空、跨边缘三类样例补洞边界可评估；采样保护区绝不被取样或覆盖。
2. 新层只包含变更区域，原图及未选区域像素保持不变，可一键比较和撤销。
3. 大选区、无有效采样、请求超时和取消有明确反馈，不写入空白成功结果。
4. 项目重开及导出保留实际补洞资源和方法元数据，不自动重新调用服务。
