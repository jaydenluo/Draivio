# F02 自动保存、恢复记录与崩溃恢复

**目标：** 中断后恢复最近的完整编辑状态，并始终保留用户主动保存的版本。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 5 天 / 无截止日期 / 不预设负责人。

**阶段：** 1；**依赖：** F01。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

按脏状态防抖并周期保存恢复副本；记录文档 ID、基准项目版本、更新时间和恢复版本；保留最近 5 个成功快照，原子写入，磁盘清理不删除手动作品。

## 入口与交互

启动时展示待恢复作品、时间和预览，可恢复为副本或丢弃；状态栏显示保存中、已恢复和失败重试；设置允许关闭自动保存。

## 范围边界

不包含云同步和多人协作；不把尚未完成的 API 请求重新提交。

## 数据、可靠性与界面约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。
- 继续“图层 / 属性 / AI 结果”右侧架构；属性随对象变化，常用表单 24px、可键盘操作、中文可理解标签；对话框/顶部放置低频复杂操作，不能全部堆到右侧。
- 无能力、空状态、处理中、部分失败、取消、重试均有真实反馈；工具入口不作为完成证据。
- 单元测试覆盖数据/几何/像素行为，组件测试覆盖关键交互；图像能力增加固定输入与输出对照，真实服务另留授权调用证据。

## 验收标准与验证样例

1. 连续输入仅按保存策略提交；旧保存异步返回不能把较新内容标成已保存。
2. 强制终止后启动可恢复完整图层与资源；最后一个损坏快照可退到上一个成功快照。
3. 磁盘满/无权限时展示原因并允许重试，手动项目与上一个成功副本不受损。
4. 恢复、另存、关闭与多项目恢复以文档 ID 隔离；用户丢弃有二次确认。
