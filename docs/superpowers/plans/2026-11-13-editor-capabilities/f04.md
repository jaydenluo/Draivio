# F04 画布尺寸、图像缩放与统一像素坐标

**目标：** 让画布、属性、选区和导出使用真实像素，显示缩放不改变图片尺寸。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 6 天 / 无截止日期 / 不预设负责人。

**阶段：** 1；**依赖：** 无。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

文档 width/height 为唯一尺寸源，替换固定 viewBox；新建常用比例与尺寸、Auto 跟随导入图；画布改尺寸提供九宫格锚点及裁切提示，图像缩放按比例重采样全部内容；支持透明背景。

## 入口与交互

新建对话框选择比例→分辨率；顶栏文档尺寸入口区分“画布大小”和“图像大小”；属性 X/Y/W/H 默认 px，百分比为可选显示单位。

## 范围边界

不改变用户已要求的 AI 输出比例/尺寸菜单；文档尺寸和模型输出尺寸分别明确标识。

## 验收标准与验证样例

1. 导入 1200×800 图片后 100% 对应实际像素；缩放视图到 50% 不改变属性和导出尺寸。
2. 画布扩边、居中裁切、图像整体缩放分别有预期坐标结果，图片/文字/笔画/蒙版同步。
3. 尺寸限 1–16384px 并结合渲染预算拒绝不安全面积；非法值不提交，裁切可撤销。
4. 任意尺寸下选区、拖拽、旋转、AI 贴回坐标一致；旧 500×625 项目迁移无漂移。
