# F10 选择并遮住与蒙版边缘精修

**目标：** 让用户修正抠图边缘，并能恢复和继续编辑。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 7 天 / 无截止日期 / 不预设负责人。

**阶段：** 3；**依赖：** F09。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

提供叠加/透明/黑白背景预览；边缘平滑、羽化、收缩/扩展、密度、去杂边，局部边缘画笔；保存参数与蒙版，不直接抹掉源像素；输出为选区或图层蒙版。

## 入口与交互

选区工具栏“优化边缘”打开临时编辑模式，确认一次提交，取消完整恢复；属性显示密度和羽化常用项。

## 范围边界

发丝精修依赖服务或明确算法能力；不把简单模糊命名为智能发丝恢复。

## 验收标准与验证样例

1. 硬边商品、半透明发丝、白底彩边样例逐项验证平滑/羽化/位移/去杂边。
2. 预览切换不改像素；确认仅一个历史项，取消不改变蒙版与源图。
3. 蒙版翻转、应用、密度和羽化组合有确定顺序，导出与重开一致。
4. 高分辨率先低清预览后全清提交，提交可取消；边界参数不出现黑边或透明度溢出。
