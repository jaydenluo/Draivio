# F14 文本框、段落排版与局部文字样式

**目标：** 在海报内完成可编辑文字排版，避免每次改字都重做图片。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 8 天 / 无截止日期 / 不预设负责人。

**阶段：** 2；**依赖：** F01, F04, R01, F15。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

区分点文字/固定文本框；自动换行、显式溢出提示；行距、字距、段落对齐；选中字符范围修改字体/字号/字重/颜色，保留中文输入法；基础文字描边与阴影复用效果接口。

## 入口与交互

文字工具创建文本框，双击进入文字编辑；属性随文字选择显示字符/段落项，框架尺寸与字体参数分开。

## 范围边界

不含专业 OpenType 全部特性、竖排和路径文字；不把栅格化当可编辑文本保存。

## 数据、可靠性与界面约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。
- 继续“图层 / 属性 / AI 结果”右侧架构；属性随对象变化，常用表单 24px、可键盘操作、中文可理解标签；对话框/顶部放置低频复杂操作，不能全部堆到右侧。
- 无能力、空状态、处理中、部分失败、取消、重试均有真实反馈；工具入口不作为完成证据。
- 单元测试覆盖数据/几何/像素行为，组件测试覆盖关键交互；图像能力增加固定输入与输出对照，真实服务另留授权调用证据。

## 验收标准与验证样例

1. 中英文混排、换行、emoji、组合字符、输入法组字不截断；局部样式范围随编辑正确移动。
2. 文本框缩放与字号缩放有明确不同，溢出可见提示且不静默丢文字。
3. 字体缺失有替代提示，换字体可撤销；使用已授权字体进行导出与重开对照。
4. 行距、字距、局部样式、描边/阴影的预览和导出一致；编辑取消和焦点快捷键无冲突。
