# F29 RAW 解码与基础显影

**目标：** 导入相机原始文件并以非破坏方式调整基础显影。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 12 天 / 无截止日期 / 不预设负责人。

**阶段：** 6；**依赖：** F30, F31, F11。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

评估并集成有明确许可证的 RAW 解码库；公布实际支持相机/格式矩阵；保留原始文件、去马赛克、相机白平衡/曝光、高光恢复及方向元数据；生成可缓存高精度图像。

## 入口与交互

打开 RAW 进入显影界面，调整并确认后作为保留 RAW 源与显影参数的对象进入文档，之后可重开显影。

## 范围边界

不承诺所有相机、镜头配置和 Camera Raw 完全等价；不包含完整镜头校正数据库。

## 验收标准与验证样例

1. 使用有授权的至少三类不同 RAW 样本验证方向、白平衡、曝光和高光处理，记录解码版本与支持矩阵。
2. 重开显影参数可编辑，原 RAW 字节不变；转入项目后离线可恢复。
3. 不支持/损坏 RAW 明确拒绝，不把内嵌 JPEG 当完整 RAW 解码成功。
4. 大文件解码可取消且不阻塞 UI，内存峰值有记录；导出经 ICC 管线转换。
