# F33 软打样、色域警告与印刷检查

**目标：** 在输出前预览指定设备的颜色表现并发现超色域问题。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 7 天 / 无截止日期 / 不预设负责人。

**阶段：** 6；**依赖：** F31, F32。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

选择目标 ICC、渲染意图、黑点补偿、模拟纸白/黑墨；原图/打样切换及并排预览；色域警告和总墨量检查；保存打样设置但不改变源像素。

## 入口与交互

视图菜单“校样颜色/校样设置”，状态区持续标明正在打样；导出前可查看检查结果。

## 范围边界

不负责打印机驱动、硬件校准和商业印刷保证；预览叠加不烘焙进普通导出。

## 验收标准与验证样例

1. 已知 RGB→印刷 ICC 样例验证渲染意图、黑点补偿和纸白模拟差异。
2. 色域警告与总墨量指标来自目标 profile/CMYK 数值，不以任意 RGB 阈值代替。
3. 开关打样前后源像素和普通导出完全一致，当前打样状态可见且可通过键盘关闭。
4. 缺失目标 profile、项目重开及跨文档切换不串设置，检查报告显示实际目标配置。
