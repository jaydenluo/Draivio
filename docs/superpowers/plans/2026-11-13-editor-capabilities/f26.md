# F26 多文档标签与状态隔离

**目标：** 同时编辑多个作品，切换时不丢状态和历史。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 6 天 / 无截止日期 / 不预设负责人。

**阶段：** 5；**依赖：** F01, F02, R02。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

文档列表、活动文档 ID、每文档图层/历史/选区/视图/脏状态独立；跨文档复制资源并重映射 ID；后台 AI 和保存任务绑定原文档；限制后台缓存。

## 入口与交互

画布顶部文档标签，显示名称/未保存点/关闭；快捷切换，关闭有未保存确认，拖入项目可打开新标签。

## 范围边界

不包含多人协作、跨窗口拖动和云项目同步。

## 数据、可靠性与界面约束

所有任务共同完成定义：
- 修改文档内容的操作可撤销；预览、取消和失败不得污染文档，异步结果绑定发起文档及版本。
- 新数据进入项目 schema、迁移、资源生命周期及保存/恢复；预览与最终导出复用相同语义。
- 继续“图层 / 属性 / AI 结果”右侧架构；属性随对象变化，常用表单 24px、可键盘操作、中文可理解标签；对话框/顶部放置低频复杂操作，不能全部堆到右侧。
- 无能力、空状态、处理中、部分失败、取消、重试均有真实反馈；工具入口不作为完成证据。
- 单元测试覆盖数据/几何/像素行为，组件测试覆盖关键交互；图像能力增加固定输入与输出对照，真实服务另留授权调用证据。

## 验收标准与验证样例

1. 两个文档有不同尺寸/选区/历史，来回切换及撤销互不影响。
2. 后台生成或保存完成回写正确文档，已关闭文档不会被悄悄重建或污染当前文档。
3. 跨文档粘贴后资源和对象 ID 独立，关闭原文档不丢素材。
4. 多标签恢复、关闭取消、内存预算下后台预览回收均有验证。
