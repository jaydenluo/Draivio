# F03 PNG、JPEG、WebP 与选区/图层导出

**目标：** 输出可直接发布的图片，并确保下载文件与编辑预览一致。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 7 天 / 无截止日期 / 不预设负责人。

**阶段：** 1；**依赖：** F01, F04。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

统一合成导出管线；提供 PNG/JPEG/WebP、像素尺寸、比例锁定、JPEG/WebP 质量、透明或指定底色；范围为整画布、选区边界裁切、选中图层；保留现有 SVG 入口。

## 入口与交互

顶栏“导出”打开紧凑对话框，展示格式、范围、输出大小和预估体积；JPEG 自动提示选择底色；记住上次设置。

## 范围边界

本项只保证 8bit sRGB；专业位深、CMYK、ICC 由独立任务接入，不冒充无损保留。

## 验收标准与验证样例

1. 三种格式由独立解码器验证 MIME、宽高和像素；PNG/WebP 保留透明，JPEG 底色正确。
2. 画布预览与导出对照覆盖旋转、翻转、文字、蒙版、分组、不透明度和调整，禁止带出选框及控制柄。
3. 选区裁切保持选区外透明，图层导出遵守其蒙版与效果，明确是否包含父组效果。
4. 外链图片 CORS/失效、超大尺寸、编码失败均可解释且不生成空白成功文件。
5. 增加后续渲染能力时统一扩展导出回归样例；取消导出不改变项目。
