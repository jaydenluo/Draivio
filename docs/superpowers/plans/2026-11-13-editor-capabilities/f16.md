# F16 调整图层与局部调整蒙版

**目标：** 一次调色影响下面多层，并通过蒙版局部控制效果。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 6 天 / 无截止日期 / 不预设负责人。

**阶段：** 4；**依赖：** F11, F12, F13, F06。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

新增 adjustment 类型图层；复用已有调整参数；按堆栈顺序影响同组合成下方内容，可剪贴到一层；支持自己的蒙版、透明度、显隐和锁定。

## 入口与交互

图层“添加调整图层”选择调整类型；属性编辑参数；图层缩略图区分调整和像素。

## 范围边界

现有图片本身的调整继续可用；不以复制所有下层图片模拟调整图层。

1. 两个像素层之间插入调整层，仅影响其下方；嵌套组与剪贴作用范围可验证。

4. 透明背景下不凭空生成底色；锁定阻止参数和蒙版修改。
