# F05 组整体变换与图层合并

**目标：** 把图层组作为整体排版，并在需要时可控地合并图层。

**Vibe Plan 字段：** feature / backlog / P2 / 估算 6 天 / 无截止日期 / 不预设负责人。

**阶段：** 2；**依赖：** F01, F04, R01。R 编号表示旧任务内工作包，创建时以旧任务 UUID 为依赖，只有工作包证据完备并经审核才能视作满足。

## 功能范围

在原任务组状态继承修复之上，建立父子变换矩阵、组包围盒、组整体移动缩放旋转；合并所选、向下合并、合并可见、拼合图像；混合/蒙版无法保留时有明确栅格化说明。

## 入口与交互

图层列表选择组后属性编辑整个组；上下文菜单提供合并命令并说明是否栅格化，合并可见默认保留隐藏层。

## 范围边界

原任务负责组隐藏/锁定/透明度继承及深复制；本项不重复计算修复工作。

## 验收标准与验证样例

1. 嵌套两级组旋转缩放后子对象局部坐标可继续编辑，解组不跳位。
2. 合并前后像素对照一致，选中范围外和隐藏层按命令语义保留。
3. 锁定及祖先锁定禁止合并或变换，混合模式导致的视觉差异有提示且不静默改变。
4. 整次合并或组拖拽仅产生一次撤销，重开项目后组矩阵与合并资源完整。
