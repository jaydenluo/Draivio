## 验证方法

离线mock只验证契约；真实模型评测单列授权、版本、成本、成功率。先建立针对行为/像素的失败用例，再实现并验证。相关测试通过后运行 `npm test -- --run`、`npm run build`、`vibeplan check`；涉及Rust时运行 `cargo check --manifest-path src-tauri/Cargo.toml`。真实服务评测与离线契约测试分开记录，外部付费调用在实施时取得授权。这里列出的是待执行检查，不是通过记录。
