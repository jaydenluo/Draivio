## 验收标准

- [ ] 每个有多个子工具的按钮都有右下角小三角。
- [ ] 点击主按钮、点击小三角、按住按钮和快捷键都能进入工具。
- [ ] 工具菜单不会遮挡当前控制点或 Composer。
- [ ] 选区可以创建、调整、组合、羽化和转为蒙版。
- [ ] 画笔、橡皮、蒙版、文字、变换和导航都有可见反馈。
- [ ] 画布缩放不会改变网页缩放。
- [ ] 画布对象修改可撤销和重做。
- [ ] `npm test -- --run`、`npm run build` 和 `cargo check` 全部通过。
