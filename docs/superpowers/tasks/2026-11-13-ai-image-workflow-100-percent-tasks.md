## 里程碑任务

- [ ] Task 1：统一文档模型和能力矩阵

- [ ] Task 6：图层、蒙版、历史和非破坏编辑

## 100% 完成判定

只有 M1–M5 的验收项全部完成，才把产品状态从“交互原型”更新为“目标工作流完成”。按钮数量不作为完成依据，必须以真实像素结果、AI provider 响应、本地恢复和失败可恢复性作为完成证据。
