# 海报排版配方

「海报排版」是本地约束布局工具，不调用生图或模型。标题、正文各自写入可编辑文字对象与对应文字图层；PNG/SVG 导出使用同一 CanvasScene。支持竖版1080×1350、方形1080×1080、横版1350×1080、自定义尺寸与安全边距。溢出会拒绝预览，不截断输入。

原图和商标可从现有图层选择，或通过本地文件选择器导入。选择现有素材会保留它的图层 ID、内容和来源，并标记锁定；导入素材分配唯一 ID，原始字节进入项目资源。新增文字、画板使用唯一 ID，保留原有文字、图层和画板，重复应用可继续编辑与保存。

预览直接使用私有候选文档的 CanvasScene，不修改作品。每次预览重新捕获文档 ID 与内容版本；应用时拒绝过期候选，重新预览后可应用。确认后一次撤销，取消与导入迟到结果不会污染作品。非通用字体需要明确确认系统回退。

第二验收周期修复了旧实现缺失文字图层、重复来源 ID、原文字被覆盖及预览基线陈旧的问题。旧 PNG 仅以手工拼接状态渲染，不能支持真实 UI 验收；现有证据已改为生产 AIComposer 录入、预览、应用后的真实状态渲染，并逐项验证 SVG 包含输入文字、文字带来的实际像素差、合法项目 encode/decode、保护来源、重复应用、取消、过期重预览和 undo/redo。证据位于 docs/evidence/poster，JSON 记录每种尺寸的文字渲染与像素差。本地布局模型请求和费用均为0。

第三验收周期进一步撤回“中文样例通过即可证明所有字体”的推论：24个 W 在第二周期三尺寸 PNG 仍越界。共享换行现按与 CanvasScene 相同的规范化字体族、字重和字距测量完整候选行及墨迹边界，并同时保留保守字形包络。Canvas 与 SVG/PNG 的后备字体可能不同，不能仅依赖 Canvas 的较小测量值；混合表情和等宽字体的实际像素回归证明了这点。无 Canvas 时使用同一包络，宽字形超出文本框会明确拒绝预览。不会截短输入或挤压字形。保守换行可能留下更多空白；这不是所有自定义字体的精确排版认证，实际系统字体缺失或替换仍需检查预览。

当前周期证据使用 fallback/native-fonts 两种后端前缀：中文、24个W、混合中文/全角/组合重音、serif、monospace，各三种尺寸；全部从生产 Composer 输入并应用，再经生产 CanvasScene 与 Resvg 渲染，核对输入全文、边距像素、可编辑图层和项目往返。native-fonts 为真实原生 Canvas 字体测量，非伪造 TextMetrics；没有可用的浏览器自动化入口，因此不冒充浏览器或跨平台人工验收。旧无前缀图片为历史周期证据，不能用于当前验收。

视觉复核还发现：当前 Resvg 字体环境会把部分表情渲染为缺字方框，即使 DOM 保留全文和像素边距通过也不能证明字形正确。因此海报预览明确拒绝表情/ZWJ组合，提示尚未验证导出字形，并保留用户输入和原作品。混合成功样例使用中文、宽拉丁、全角和组合重音；不宣称表情海报支持。通用文字编辑器的字素保留逻辑不受此限制。
