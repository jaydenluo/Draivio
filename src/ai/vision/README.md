# 语义目标与蒙版

选择普通图像图层，在选区工具顶部点“语义目标与蒙版”。填写语义分割服务的完整 HTTP(S) 地址，选择主体、背景或指定物体并输入描述，再点“分析目标”。多个对象或置信度低于 80% 时必须明确点选候选。羽化以文档像素计算；“应用为选区”或“应用为图层蒙版”各产生一个可撤销操作。图层蒙版保存进项目，预览和导出使用相同软 alpha。

仓库现提供 scripts/semantic/gateway.py 的真实 U2Netp ONNX 显著主体推理，安装/启动见 scripts/semantic/README.md。指定物体的文本实例分割不由 U2Netp 支持。边缘连通去背景算法不作为此工具的语义能力。本工具不会自动下载模型，不会把几何框、空响应或去背景规则伪造成分割蒙版。未配置或不可用时显示错误且不修改文档。

## 服务来源与配置

地址由用户提供，可以是用户维护的本地推理服务，或实现下列协议的分割网关。示例 `http://127.0.0.1:8000/segment` 只是地址格式示例；默认本地实际网关为 http://127.0.0.1:8766/segment，需要用户启动；未声称第三方供应商已实现该协议。服务需运行实际语义分割模型，并返回真实像素 alpha 及候选置信度。现有 selectSubject hook 只返回 Selection，不能提供对象候选和置信度，因此没有静默适配成完整语义能力。

地址仅存在本机 localStorage，不写入项目；协议当前无凭据设置，带 URL 用户名/密码的地址被拒绝。浏览器服务需允许 CORS；请求复用 requestJson 的超时、响应大小、取消和禁止重定向策略。

POST 请求：

```json
{"image":"data:image/png;base64,...","target":"object","query":"衣服","output":"alpha-candidates-v1"}
```

主体发送 `target: "subject"`，指定物体发送 `target: "object"` 及 query。背景同样请求主体 alpha，再在原图映射和羽化后按 `255-alpha` 取补集。image 为当前图层原始资源的等比例 PNG，长边最多 1024，不包含其旋转/缩放；返回 alpha 必须覆盖完整输入图像，不能是未声明的裁剪框或 letterbox。

成功响应（alpha 是逐行 0–255 整数，允许半透明发丝/玻璃）：

```json
{"width":2,"height":2,"candidates":[
 {"id":"shirt-left","label":"衣服","confidence":0.94,"alpha":[0,128,255,0]},
 {"id":"shirt-right","label":"衣服","confidence":0.91,"alpha":[255,0,0,64]}
]}
```

宽高是模型分析网格；候选 mask 长度必须严格等于 width×height。响应必须包含至少一个非空候选，ID 不重复，confidence 在 0–1。非 2xx、无候选、空 alpha、越界/非整数 alpha、错误尺寸、取消、不可逆变换均失败，不生成替代 mask。响应最大 32MB，网格最多 4096×4096 且总分析像素最多 4194304。

映射使用像素中心和完整图层祖先仿射矩阵逆变换，按最近邻恢复 alpha 的原始含义；不拿低清包围框直接缩放。图层蒙版再转到目标的局部百分比坐标，保护嵌套旋转缩放语义。

测试中的 HTTP 响应是固定契约样例，验证客户端处理、像素映射和交互，不是语义模型准确率证据。没有调用付费或外部分割服务。现已真实调用本地 U2Netp CPU 推理，详见 scripts/semantic/README.md；指定物体模型的质量与兼容部署仍无实测记录。
