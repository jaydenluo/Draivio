# Draivio

Draivio 是一款画布优先的 AI 图片创作桌面软件。当前工作区实现了已确认的四区界面：顶部项目栏、左侧画布工具、中央画布、右侧上下文/图层面板和底部操作历史。

Photoshop 式工具交互规范见 [agent.md](agent.md)，四阶段实现计划见 [photoshop-tool-system-plan.md](docs/superpowers/plans/2026-11-13-photoshop-tool-system-plan.md)，任务清单见 [photoshop-tool-system-tasks.md](docs/superpowers/tasks/2026-11-13-photoshop-tool-system-tasks.md)。

## 统一生图与编辑操作区

生图与编辑共用中央画布底部的 AI Composer：

- 顶部模式按钮在“修改当前图”和“生成新内容”之间切换。自定义供应商支持真实生成及声明能力内的蒙版编辑，候选需检查后采用；一句话编辑支持离线规则与配置的推理模型。官方云服务使用幕影共享账号，支持登录、注册、读取可用模型与积分余额；生成前查询服务端报价，结算由云端完成。服务地址默认 https://www.moviviz.com，可在登录窗口的“云服务地址”中配置。详见 [云服务接入说明](docs/user-guide/cloud-account.md)。
- 中间是同一个自然语言输入框，描述想生成或修改的内容。
- 输入框下方可以直接选择模型、比例与分辨率、数量；编辑模式额外显示变化强度。比例与分辨率合并为一个入口：一级为常用比例，二级为对应像素尺寸；支持完整 Auto，以及固定比例下的 Auto 分辨率。比例与尺寸一起保存，支持撤销和重做。数量首次默认为 1 张，并在本机保存上次选择，刷新或重新打开后恢复。
- 点击参数会打开轻量弹层，选择后立即反映在按钮上；请求前显示供应商、请求次数、费用估算或费用未知提示和运行状态。
- 右侧面板只保留当前上下文和图层，避免把生成参数重复放在侧栏。
- Composer 顶部提供位置切换：默认悬浮在画布底部，也可以停靠到右侧操作区；切换时会保留当前提示词、模式和参数。
- 右上角的 `−` 可以最小化为小胶囊，点击 `＋` 恢复完整对话框；最小化状态在两个位置之间切换时也会保留。

## 多文档标签

画布上方提供文档标签。点击 `＋` 或顶部「新建」创建独立文档；「打开」和拖入 `.draivio` 项目会新增标签，保留当前作品。最多同时打开 16 个文档，各自保存图层、选区、提示词、撤销记录及画布视图；后台生成和保存结果仍归属原文档。

标签上的圆点表示尚未保存。关闭时可选择保存并关闭、不保存或取消；重新打开软件时可恢复本地缓存的多个文档。恢复副本需重新保存，撤销记录不跨重启保留；较大项目应主动保存为本地项目文件。

快捷键：`Ctrl/Cmd+N` 新建，`Ctrl/Cmd+O` 打开，`Ctrl/Cmd+S` 保存，`Ctrl/Cmd+Shift+S` 另存为，`Ctrl/Cmd+W` 关闭当前文档；`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换文档，聚焦标签时支持左右方向键。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可查看工作区。

Tauri 桌面开发：

```bash
npm run tauri:dev
```

也可以直接运行根目录脚本。脚本会先清理 `5173` 端口，再启动 Tauri 开发模式；终端实时显示日志，同时保存到 `logs/dev-日期时间.log`：

```bash
./dev.sh
```

脚本默认启动 `npm run tauri:dev`。只想启动浏览器预览时可以运行：

```bash
DRAIVIO_DEV_COMMAND="npm run dev" ./dev.sh
```

可以通过 `DRAIVIO_DEV_PORT` 修改清理的端口，通过 `DRAIVIO_LOG_DIR` 修改日志目录。

构建桌面安装包：

```bash
npm run tauri:build
```

## 验证

```bash
npm test -- --run
npm run build
```

当前工作区提供选区/路径、笔触与蒙版、裁剪/变换、文字/形状/颜色/导航及本地图片导入导出。AI Composer 已接入配置的兼容供应商接口及本地可撤销工具。浏览器只持久化服务元数据，密钥只在会话内存；桌面端目前服务配置与密钥均仅会话保留，不再写入明文 SQLite。重启后需重新配置；官方余额和支付接口尚未接入，不展示虚构积分。

中央画布和右侧操作面板之间有可拖拽分隔条，默认右侧面板宽度为 320px，可调整到 240～520px；分隔条获得焦点后也可以使用左右方向键调整。

画布缩放只作用于画布内容：可以使用画布底部的缩放按钮，也支持触摸屏或触控板双指捏合；网页窗口本身不会跟着缩放。撤销/重做、导出、账户菜单、历史筛选/清空/导入、图层新增/选择/显隐/属性编辑等按钮均已接入当前前端状态。

撤销/重做已移动到画布右下角，与缩放控件放在一起。底部历史区左侧的箭头可以折叠或展开历史缩略图；折叠时画布会自动获得更多垂直空间。左侧画布工具会在中央画布上产生对应操作反馈：画笔、橡皮、移动、平移、文字、取色、选区、蒙版和裁剪。

## 模型与参数指南

点击 AI 输入框右上方的「模型指南」可查看模型选型、强度与其他参数的区别，以及使用建议。完整说明见 [图片模型与参数指南](docs/user-guide/image-model-guide.md)，内含官方来源、核查日期和待核实标记。模型名称和强度值不证明供应商支持；实际可用性以已配置协议及模型能力声明为准。


## 当前画布工具

画布工具遵循 Photoshop 操作习惯：左侧组按钮右下角三角可打开子工具，长按约 250ms 也可打开；Space 临时平移，Esc 取消当前手势，Enter 提交路径、裁剪或变换。选区支持矩形、椭圆、套索、多边形、贝塞尔、添加/减去/相交、羽化、反选、扩展/收缩和蒙版。画笔、橡皮和蒙版笔触按连续手势记录，画布内缩放与双指捏合不会缩放网页。

文字工具的字体预设只引用用户系统已安装的字体，不把字体文件打包进软件。预设包含 Noto Sans/Serif SC、思源黑体/宋体、霞鹜文楷、Inter、Source Sans 3、IBM Plex Sans、JetBrains Mono、IBM Plex Mono、Source Code Pro 和 Fira Code；这些预设按 SIL Open Font License 1.1 标注，未检测到的字体会显示回退提示。取色工具会在颜色/填充下级菜单保存最近 20 个颜色，并写入本地浏览器/Tauri WebView 存储。

## 开源发布与自动更新

桌面包通过 GitHub Actions 在 `v*` 标签下自动构建，签名更新由 Tauri updater 提供。首次发布前请阅读 [桌面版发布与自动更新](docs/release/desktop-release.md)，配置 `TAURI_SIGNING_PRIVATE_KEY` 与 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` 两个 GitHub Actions Secrets。私钥不要提交到仓库。
