# Draivio

Draivio 是一款画布优先的 AI 图片创作桌面软件。当前工作区实现了已确认的四区界面：顶部项目栏、左侧画布工具、中央画布、右侧上下文/图层面板和底部操作历史。

Photoshop 式工具交互规范见 [agent.md](agent.md)，四阶段实现计划见 [photoshop-tool-system-plan.md](docs/superpowers/plans/2026-11-13-photoshop-tool-system-plan.md)，任务清单见 [photoshop-tool-system-tasks.md](docs/superpowers/tasks/2026-11-13-photoshop-tool-system-tasks.md)。

## 统一生图与编辑操作区

生图与编辑共用中央画布底部的 AI Composer：

- 顶部模式按钮在“修改当前图”和“生成新内容”之间切换；有选区时自动使用选区范围，无选区时使用整张画布。两种模式都新增结果图层并保留原图，可撤销和重做。当前执行仍为模拟流程，保存提示词、来源图层、范围和参数，尚未接入真实模型与图片合成。
- 中间是同一个自然语言输入框，描述想生成或修改的内容。
- 输入框下方可以直接选择模型、比例与分辨率、数量；编辑模式额外显示变化强度。比例与分辨率合并为一个入口：一级为常用比例，二级为对应像素尺寸；支持完整 Auto，以及固定比例下的 Auto 分辨率。比例与尺寸一起保存，支持撤销和重做。
- 点击参数会打开轻量弹层，选择后立即反映在按钮上；执行按钮显示预计积分和运行状态。
- 右侧面板只保留当前上下文和图层，避免把生成参数重复放在侧栏。
- Composer 顶部提供位置切换：默认悬浮在画布底部，也可以停靠到右侧操作区；切换时会保留当前提示词、模式和参数。
- 右上角的 `−` 可以最小化为小胶囊，点击 `＋` 恢复完整对话框；最小化状态在两个位置之间切换时也会保留。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可查看工作区。

Tauri 桌面开发：

```bash
npm run tauri:dev
```

也可以直接运行根目录脚本。脚本会先清理 `5173` 端口，再启动 Tauri 开发模式；终端实时显示日志，同时保存到 `logs/dev-日期时间.log`：

```bash
./dev.sh
```

脚本默认启动 `npm run tauri:dev`。只想启动浏览器预览时可以运行：

```bash
DRAIVIO_DEV_COMMAND="npm run dev" ./dev.sh
```

可以通过 `DRAIVIO_DEV_PORT` 修改清理的端口，通过 `DRAIVIO_LOG_DIR` 修改日志目录。

构建桌面安装包：

```bash
npm run tauri:build
```

## 验证

```bash
npm test -- --run
npm run build
```

当前这一阶段是前端工作区实现。生成按钮使用本地模拟状态，图片画布使用内置 SVG 示例；官方云服务、用户 API Key 的 SQLite 存储、Tauri 原生文件能力和真实模型请求会在下一阶段接入。

中央画布和右侧操作面板之间有可拖拽分隔条，默认右侧面板宽度为 320px，可调整到 240～520px；分隔条获得焦点后也可以使用左右方向键调整。

画布缩放只作用于画布内容：可以使用画布底部的缩放按钮，也支持触摸屏或触控板双指捏合；网页窗口本身不会跟着缩放。顶部撤销/重做、导出、账户菜单、历史筛选/清空/导入、图层新增/选择/显隐/属性编辑等按钮均已接入当前前端状态。

撤销/重做已移动到画布右下角，与缩放控件放在一起。底部历史区左侧的箭头可以折叠或展开历史缩略图；折叠时画布会自动获得更多垂直空间。左侧画布工具会在中央画布上产生对应操作反馈：画笔、橡皮、移动、平移、文字、取色、选区、蒙版和裁剪。
